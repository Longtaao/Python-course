## 🚀 怎么用

**在线看**：直接点上面表格里的链接，GitHub 会把 Markdown 渲染成网页。

**下载到本地**：

```bash
git clone https://github.com/Longtaao/Python-course.git
```

或者点页面右上角 **Code → Download ZIP**，解压即用（适合只想看、不打算改的情况）。

**导入 Obsidian**：把 `notes/` 文件夹当作库（vault）打开即可，章节间的跳转链接可以直接点击。

## 🛠️ 环境准备

```bash
# 验证
python --version
pip --version

# 应用篇常用库（一次装齐）
pip install openpyxl jieba matplotlib wordcloud networkx requests beautifulsoup4 pandas numpy scikit-learn pygame opencv-python pyttsx3 sympy scipy
```

国内网络慢时换清华镜像：

```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple 包名
```

> 📌 建议给每个应用章建一个独立虚拟环境：`python -m venv venv`，避免依赖版本打架。

## 🧭 学习路线

```text
第 1 章 → 第 2 章 → 第 3 章 → 第 4 章 → 第 5 章 → 第 6 章
                              ↓
              ┌───────────────┼───────────────┐
              ↓               ↓               ↓
        文本/图表(7,9)    界面/数据库(8,10)   数据/AI(11,12)
              └───────────────┼───────────────┘
                              ↓
                    游戏/图像/语音(13,14)
```

- **只想快速上手**：1 → 2 → 3 → 4 → 9（画图）→ 11（pandas）
- **课程/考试导向**：1–6 必须扎实，7–10 至少各做一个案例
- **做项目导向**：基础过一遍后，直接挑第 7–14 章里感兴趣的案例，边做边补语法
