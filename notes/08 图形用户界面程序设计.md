
# 08 图形用户界面程序设计

> **一句话：** tkinter 程序 = **建窗口 → 摆组件 → 绑事件 → mainloop()**；组件用 `pack`/`grid`/`place` 排版，用 `command` 或 `bind` 响应操作。

## 8.1 窗口与基本套路

```python
import tkinter as tk

root = tk.Tk()
root.title("我的第一个窗口")
root.geometry("400x300")       # 宽 x 高
root.mainloop()                # 进入事件循环，窗口保持显示
```

> [!WARNING]
> **忘了 mainloop 会怎样**
> 窗口一闪而过，或者根本不显示。`mainloop()` 是 GUI 程序的主循环，负责监听鼠标、键盘和重绘。

### 常用窗口设置

```python
root.title("标题")
root.geometry("500x400+200+100")   # 宽x高+左边距+上边距
root.resizable(False, False)       # 禁止缩放
root.configure(bg="#f0f0f0")       # 背景色
root.iconbitmap("app.ico")         # 图标（Windows）
```

### 最小完整示例

```python
import tkinter as tk

def say_hello():
    label.config(text="你好，世界！")

root = tk.Tk()
root.title("示例")
root.geometry("300x150")

label = tk.Label(root, text="点下面的按钮")
label.pack(pady=10)

button = tk.Button(root, text="点我", command=say_hello)
button.pack()

root.mainloop()
```

注意：`command=say_hello` **不要加括号**。加括号会在创建按钮时立刻执行函数。

## 8.2 常用组件

### Label 标签

```python
label = tk.Label(
    root,
    text="用户名",
    font=("微软雅黑", 14),
    fg="blue",
    bg="white",
    width=10,
    anchor="w",
)
label.pack()
```

### Button 按钮

```python
def on_click():
    print("被点击了")

btn = tk.Button(root, text="提交", width=10, command=on_click)
btn.pack()
```

### Entry 单行文本框

```python
entry = tk.Entry(root, width=30)
entry.pack()

entry.insert(0, "默认文字")       # 写入
text = entry.get()                # 读取
entry.delete(0, tk.END)           # 清空

password = tk.Entry(root, show="*")   # 密码框
```

### Text 多行文本框

```python
text = tk.Text(root, height=10, width=40)
text.pack()

text.insert("end", "第一行\n")     # 末尾插入
content = text.get("1.0", "end-1c")  # 从第1行第0列到末尾（去掉自动换行）
text.delete("1.0", "end")           # 清空
```

> [!TIP]
> **记不住索引？**
> `"1.0"` 表示第 1 行第 0 个字符；`"end"` 表示末尾；`"end-1c"` 表示末尾去掉最后一个换行符。

### Radiobutton 单选按钮

```python
choice = tk.StringVar(value="A")

tk.Radiobutton(root, text="选项 A", variable=choice, value="A").pack()
tk.Radiobutton(root, text="选项 B", variable=choice, value="B").pack()

print(choice.get())
```

同一组单选按钮必须绑定**同一个变量**。

### Checkbutton 复选框

```python
agree = tk.BooleanVar()
tk.Checkbutton(root, text="同意协议", variable=agree).pack()

print(agree.get())     # True / False
```

多选时每个选项用独立变量。

### Frame 框架

用于分组和布局：

```python
top = tk.Frame(root, bg="lightblue")
top.pack(fill="x")

bottom = tk.Frame(root)
bottom.pack()

tk.Label(top, text="顶部区域").pack()
tk.Button(bottom, text="底部按钮").pack()
```

### Notebook 选项卡

```python
from tkinter import ttk

notebook = ttk.Notebook(root)
notebook.pack(fill="both", expand=True)

page1 = tk.Frame(notebook)
page2 = tk.Frame(notebook)

notebook.add(page1, text="基本信息")
notebook.add(page2, text="详细设置")

tk.Label(page1, text="这里是第一页").pack()
tk.Label(page2, text="这里是第二页").pack()
```

### Menu 菜单

```python
menubar = tk.Menu(root)

file_menu = tk.Menu(menubar, tearoff=0)
file_menu.add_command(label="打开", command=lambda: print("打开"))
file_menu.add_command(label="保存", command=lambda: print("保存"))
file_menu.add_separator()
file_menu.add_command(label="退出", command=root.destroy)

menubar.add_cascade(label="文件", menu=file_menu)
root.config(menu=menubar)
```

## 8.3 三种布局方法

### pack：按顺序排列

```python
tk.Label(root, text="上").pack(side="top")
tk.Label(root, text="下").pack(side="bottom")
tk.Label(root, text="左").pack(side="left")
tk.Label(root, text="右").pack(side="right")

frame.pack(fill="both", expand=True)   # 填满并随窗口伸缩
```

### grid：网格排列（最常用）

```python
tk.Label(root, text="用户名").grid(row=0, column=0, padx=5, pady=5, sticky="e")
tk.Entry(root).grid(row=0, column=1, padx=5, pady=5)

tk.Label(root, text="密码").grid(row=1, column=0, padx=5, pady=5, sticky="e")
tk.Entry(root, show="*").grid(row=1, column=1, padx=5, pady=5)

tk.Button(root, text="登录").grid(row=2, column=0, columnspan=2, pady=10)
```

| 参数 | 作用 |
| --- | --- |
| `row` / `column` | 行号 / 列号（从 0 开始） |
| `sticky` | 对齐：`n/s/e/w`，可组合 `"nsew"` |
| `padx` / `pady` | 外边距 |
| `columnspan` / `rowspan` | 跨列 / 跨行 |

### place：绝对坐标

```python
tk.Label(root, text="固定位置").place(x=50, y=30)
```

适合精确摆放，但窗口缩放时不会自适应。

> [!WARNING]
> **不要混用 pack 和 grid**
> 在**同一个父容器**里同时用 `pack()` 和 `grid()`，程序会卡死或报错。可以外层用 pack、内层 Frame 用 grid。

## 8.4 常用对话框

```python
from tkinter import messagebox, colorchooser, filedialog

# 消息框
messagebox.showinfo("提示", "操作成功")
messagebox.showwarning("警告", "请输入内容")
messagebox.showerror("错误", "文件不存在")
result = messagebox.askyesno("确认", "确定要删除吗？")   # True/False

# 颜色选择
color = colorchooser.askcolor(title="选择颜色")
print(color)      # ((255, 0, 0), '#ff0000')

# 文件选择
path = filedialog.askopenfilename(
    title="选择文件",
    filetypes=[("文本文件", "*.txt"), ("所有文件", "*.*")]
)
save_path = filedialog.asksaveasfilename(
    defaultextension=".txt",
    filetypes=[("文本文件", "*.txt")]
)
```

> [!NOTE]
> **对话框是模态的**
> 弹窗没关闭前，主窗口不能操作。`askyesno` 会返回布尔值，记得用变量接住。

## 8.5 事件驱动

### command：按钮点击

```python
def handler():
    print("点击")

tk.Button(root, text="按钮", command=handler).pack()
```

需要传参数时用 lambda：

```python
tk.Button(root, text="A", command=lambda: choose("A")).pack()
```

### bind：绑定任意事件

```python
def on_click(event):
    print("点击位置：", event.x, event.y)
    print("触发组件：", event.widget)

label = tk.Label(root, text="点我")
label.pack()
label.bind("<Button-1>", on_click)      # 左键单击
```

常用事件：

| 事件 | 含义 |
| --- | --- |
| `<Button-1>` | 鼠标左键单击 |
| `<Button-3>` | 鼠标右键单击 |
| `<Double-Button-1>` | 双击 |
| `<Key>` | 任意按键 |
| `<Return>` | 回车 |
| `<Motion>` | 鼠标移动 |
| `<Enter>` / `<Leave>` | 鼠标进入/离开组件 |

### 事件对象常用属性

```python
event.x, event.y        # 相对组件坐标
event.x_root, event.y_root  # 相对屏幕坐标
event.widget            # 触发事件的组件
event.keysym            # 按键名，如 "Return"、"a"
event.char              # 按键字符
```

### 案例：简单选择题

```python
import tkinter as tk
from tkinter import messagebox

def submit():
    if answer.get() == "B":
        messagebox.showinfo("结果", "回答正确！")
    else:
        messagebox.showerror("结果", "回答错误，正确答案是 B")

root = tk.Tk()
root.title("选择题")
root.geometry("320x220")

tk.Label(root, text="Python 的创始人是？", font=("微软雅黑", 12)).pack(pady=10)

answer = tk.StringVar(value="")
for text in ["A. Dennis Ritchie", "B. Guido van Rossum",
             "C. James Gosling", "D. Bjarne Stroustrup"]:
    tk.Radiobutton(root, text=text, variable=answer,
                   value=text[0]).pack(anchor="w", padx=20)

tk.Button(root, text="提交", command=submit).pack(pady=8)
root.mainloop()
```

### 案例：健康系数计算

BMI = 体重(kg) / 身高(m)²

```python
import tkinter as tk
from tkinter import messagebox

def calc():
    try:
        height = float(entry_h.get()) / 100
        weight = float(entry_w.get())
        bmi = weight / height ** 2
        if bmi < 18.5:
            level = "偏瘦"
        elif bmi < 24:
            level = "正常"
        elif bmi < 28:
            level = "偏胖"
        else:
            level = "肥胖"
        label_result.config(text=f"BMI = {bmi:.1f}（{level}）")
    except ValueError:
        messagebox.showerror("输入错误", "请输入数字")

root = tk.Tk()
root.title("BMI 计算器")

tk.Label(root, text="身高(cm)").grid(row=0, column=0, padx=8, pady=8)
entry_h = tk.Entry(root)
entry_h.grid(row=0, column=1)

tk.Label(root, text="体重(kg)").grid(row=1, column=0, padx=8, pady=8)
entry_w = tk.Entry(root)
entry_w.grid(row=1, column=1)

tk.Button(root, text="计算", command=calc).grid(row=2, column=0, columnspan=2, pady=8)
label_result = tk.Label(root, text="")
label_result.grid(row=3, column=0, columnspan=2)

root.mainloop()
```

### 案例：简易文本编辑器

```python
import tkinter as tk
from tkinter import filedialog, messagebox

def new_file():
    text.delete("1.0", "end")

def open_file():
    path = filedialog.askopenfilename(filetypes=[("文本文件", "*.txt")])
    if path:
        with open(path, encoding="utf-8") as f:
            text.delete("1.0", "end")
            text.insert("1.0", f.read())

def save_file():
    path = filedialog.asksaveasfilename(defaultextension=".txt")
    if path:
        with open(path, "w", encoding="utf-8") as f:
            f.write(text.get("1.0", "end-1c"))
        messagebox.showinfo("提示", "保存成功")

root = tk.Tk()
root.title("简易记事本")
root.geometry("600x400")

menubar = tk.Menu(root)
file_menu = tk.Menu(menubar, tearoff=0)
file_menu.add_command(label="新建", command=new_file)
file_menu.add_command(label="打开", command=open_file)
file_menu.add_command(label="保存", command=save_file)
file_menu.add_separator()
file_menu.add_command(label="退出", command=root.destroy)
menubar.add_cascade(label="文件", menu=file_menu)
root.config(menu=menubar)

text = tk.Text(root, wrap="word")
text.pack(fill="both", expand=True)

root.mainloop()
```

## ⚠️ 本章易错点

1. 忘记 `root.mainloop()`，窗口不显示。
2. `command=func()` 加括号，函数在创建时就被执行。
3. 同一个父容器里混用 `pack()` 和 `grid()`，布局卡死。
4. `grid()` 行号列号从 0 开始，写错会错位或重叠。
5. 读取 Entry 用 `get()`，设置用 `insert()` / `delete()`，不是 `text` 属性。
6. Text 取值用 `get("1.0", "end-1c")`，直接用 `get("1.0", "end")` 会多一个换行。
7. 单选按钮没绑定同一个 `variable`，导致可以同时选中。
8. 事件处理函数参数写错，`bind` 的回调必须接收 `event`。
9. 窗口缩放后组件不跟随，需要 `fill` / `expand` / `sticky`。
10. 中文显示成方框，需指定支持中文的字体（如「微软雅黑」）。
