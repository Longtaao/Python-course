## 13.1 基本操作


### 最小游戏框架

```python
import pygame
import sys

pygame.init()                                  # 初始化

screen = pygame.display.set_mode((800, 600))   # 窗口大小
pygame.display.set_caption("我的游戏")

clock = pygame.time.Clock()
running = True

while running:
    # 1. 处理事件
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # 2. 更新状态（这里暂时没有）

    # 3. 绘制
    screen.fill((255, 255, 255))               # 白色背景
    pygame.display.flip()                      # 把画好的内容显示出来

    # 4. 控制帧率
    clock.tick(60)                             # 最高 60 帧/秒

pygame.quit()
sys.exit()
```

这四步就是游戏的「心跳」，所有游戏都是它的扩展。

> [!WARNING]
> **三个最容易忘**
> 1. `pygame.init()` 初始化。
> 2. `pygame.display.flip()` / `update()` 刷新画面，否则一直黑屏。
> 3. `clock.tick(60)` 限制帧率，否则 CPU 跑满、动画速度因电脑而异。

## 13.2 画面与动画

### Surface 与 Rect

- **Surface**：一张画布/图片，可以绘制、粘贴。
- **Rect**：矩形区域，记录位置 `(x, y)` 和大小 `(width, height)`。

```python
rect = pygame.Rect(100, 100, 50, 80)
print(rect.x, rect.y, rect.width, rect.height)
print(rect.center)        # 中心点
print(rect.right, rect.bottom)

rect.x += 5               # 移动
rect.move_ip(5, 0)        # 原地移动
```

### 绘制基本图形

```python
pygame.draw.rect(screen, (255, 0, 0), (100, 100, 120, 80))
pygame.draw.rect(screen, (0, 0, 255), (300, 100, 120, 80), 3)   # 线宽 3，空心
pygame.draw.circle(screen, (0, 200, 0), (400, 300), 50)
pygame.draw.line(screen, (0, 0, 0), (0, 0), (800, 600), 2)
pygame.draw.polygon(screen, (255, 165, 0), [(500, 500), (550, 450), (600, 500)])
```

### 加载与显示图片

```python
player_img = pygame.image.load("player.png").convert_alpha()
player_rect = player_img.get_rect(center=(400, 300))

screen.blit(player_img, player_rect)     # 把图片贴到屏幕上
```

- `convert()`：转换像素格式，提升绘制速度（有透明通道用 `convert_alpha()`）。
- `blit(图像, 位置)`：位置可以是 `(x, y)` 或 `Rect`。

### 动画的本质

```python
x = 0

while running:
    # 事件处理...

    x += 3                          # 每帧移动 3 像素
    if x > 800:
        x = -50

    screen.fill((255, 255, 255))
    pygame.draw.circle(screen, (255, 0, 0), (x, 300), 30)
    pygame.display.flip()
    clock.tick(60)
```

动画 = **每帧擦掉旧画面、改变位置、画新画面**。

> [!TIP]
> **用 delta time 让速度稳定**
> `clock.tick(60)` 返回距上一帧的毫秒数。`x += speed * dt` 能让不同帧率下速度一致；简单项目直接用固定帧率也够。

### 文字

```python
font = pygame.font.SysFont("simhei", 32)     # 中文字体
text = font.render("得分: 10", True, (0, 0, 0))
screen.blit(text, (10, 10))
```

`SysFont` 在 Windows 上可以用 `"simhei"`（黑体）、`"microsoftyahei"`。

## 13.3 精灵与碰撞检测

### 为什么用 Sprite

如果游戏里有 100 个雪花、20 条鱼，用普通列表管理位置、图片、更新逻辑会很乱。`Sprite` 把「图片 + 位置 + 更新方法」打包，`Group` 批量管理。

### 定义精灵

```python
import pygame

class Snowflake(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = pygame.Surface((8, 8), pygame.SRCALPHA)
        pygame.draw.circle(self.image, (255, 255, 255), (4, 4), 4)
        self.rect = self.image.get_rect(center=(x, y))
        self.speed = 2

    def update(self):
        self.rect.y += self.speed
        if self.rect.top > 600:
            self.rect.bottom = 0
```

### 精灵组

```python
all_snow = pygame.sprite.Group()

for _ in range(100):
    all_snow.add(Snowflake(
        x=random.randint(0, 800),
        y=random.randint(-600, 0)
    ))

# 每帧
all_snow.update()       # 调用每个精灵的 update()
all_snow.draw(screen)   # 绘制每个精灵
```

`Group` 自动遍历，不用手写循环。

### 碰撞检测

**矩形碰撞**（最常用，快）：

```python
if player.rect.colliderect(fish.rect):
    print("碰到了")
```

**精灵与组**：

```python
# 返回与 player 碰撞的精灵列表；True 表示碰撞后从组中删除
hit_list = pygame.sprite.spritecollide(player, fish_group, True)

if hit_list:
    score += 1
```

**组与组**：

```python
# 两组之间所有碰撞；两个 True 分别表示删除碰撞的精灵
pygame.sprite.groupcollide(bullets, enemies, True, True)
```

> [!NOTE]
> **碰撞检测的时机**
> 先把所有对象的位置更新完，再检测碰撞。否则会出现「已经穿过去了才算碰到」或「碰不到」的问题。

## 13.4 事件处理

### 事件队列

```python
for event in pygame.event.get():
    if event.type == pygame.QUIT:
        running = False
    elif event.type == pygame.KEYDOWN:
        if event.key == pygame.K_SPACE:
            print("发射")
    elif event.type == pygame.MOUSEBUTTONDOWN:
        print("点击位置：", event.pos, "按钮：", event.button)
```

常用事件：

| 事件 | 含义 |
| --- | --- |
| `QUIT` | 关闭窗口 |
| `KEYDOWN` / `KEYUP` | 按下/松开按键 |
| `MOUSEBUTTONDOWN` | 鼠标按下 |
| `MOUSEMOTION` | 鼠标移动 |

### 持续按键（更适合移动）

```python
keys = pygame.key.get_pressed()

if keys[pygame.K_LEFT]:
    player.rect.x -= 5
if keys[pygame.K_RIGHT]:
    player.rect.x += 5
if keys[pygame.K_UP]:
    player.rect.y -= 5
if keys[pygame.K_DOWN]:
    player.rect.y += 5
```

`KEYDOWN` 只在按下瞬间触发一次；`get_pressed()` 适合「按住持续移动」。

### 鼠标

```python
mouse_x, mouse_y = pygame.mouse.get_pos()
mouse_buttons = pygame.mouse.get_pressed()   # (左, 中, 右)
```

## 13.5 案例：飘雪动画

```python
import pygame
import random
import sys

pygame.init()
screen = pygame.display.set_mode((800, 600))
pygame.display.set_caption("飘雪")
clock = pygame.time.Clock()

class Snowflake(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((8, 8), pygame.SRCALPHA)
        pygame.draw.circle(self.image, (255, 255, 255), (4, 4), 4)
        self.rect = self.image.get_rect(
            center=(random.randint(0, 800), random.randint(-600, 0))
        )
        self.speed = random.randint(1, 3)
        self.drift = random.uniform(-0.5, 0.5)

    def update(self):
        self.rect.y += self.speed
        self.rect.x += self.drift
        if self.rect.top > 600:
            self.rect.bottom = 0
            self.rect.x = random.randint(0, 800)

snows = pygame.sprite.Group()
for _ in range(150):
    snows.add(Snowflake())

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    snows.update()

    screen.fill((20, 30, 60))
    snows.draw(screen)
    pygame.display.flip()
    clock.tick(60)

pygame.quit()
sys.exit()
```

要点：

- 每片雪花有独立速度和横向漂移。
- 落到底部后从顶部重新开始，形成循环。
- 深色背景衬托白色雪花。

## 13.6 案例：抓鱼小游戏

```python
import pygame
import random
import sys

pygame.init()
WIDTH, HEIGHT = 800, 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("抓鱼")
clock = pygame.time.Clock()
font = pygame.font.SysFont("simhei", 30)

class Player(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((60, 40), pygame.SRCALPHA)
        pygame.draw.ellipse(self.image, (255, 165, 0), (0, 0, 60, 40))
        self.rect = self.image.get_rect(center=(WIDTH // 2, HEIGHT - 60))
        self.speed = 8

    def update(self):
        keys = pygame.key.get_pressed()
        if keys[pygame.K_LEFT]:
            self.rect.x -= self.speed
        if keys[pygame.K_RIGHT]:
            self.rect.x += self.speed
        self.rect.clamp_ip(screen.get_rect())   # 不让它跑出窗口

class Fish(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((40, 25), pygame.SRCALPHA)
        pygame.draw.ellipse(self.image, (0, 150, 255), (0, 0, 40, 25))
        self.rect = self.image.get_rect(
            center=(random.randint(30, WIDTH - 30), -20)
        )
        self.speed = random.randint(2, 6)

    def update(self):
        self.rect.y += self.speed
        if self.rect.top > HEIGHT:
            self.kill()          # 从所有组中移除

player = Player()
fishes = pygame.sprite.Group()
spawn_timer = 0
score = 0

running = True
while running:
    dt = clock.tick(60)

    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # 定时生成鱼
    spawn_timer += dt
    if spawn_timer > 500:
        fishes.add(Fish())
        spawn_timer = 0

    player.update()
    fishes.update()

    # 碰撞：碰到就删除鱼
    hits = pygame.sprite.spritecollide(player, fishes, True)
    score += len(hits)

    screen.fill((135, 206, 235))
    screen.blit(font.render(f"得分: {score}", True, (0, 0, 0)), (10, 10))
    screen.blit(player.image, player.rect)
    fishes.draw(screen)

    pygame.display.flip()

pygame.quit()
sys.exit()
```

扩展方向：

- 加「炸弹鱼」，碰到扣分。
- 加音效 `pygame.mixer.Sound("hit.wav").play()`。
- 加开始/结束界面和最高分记录。
- 用真实图片替换 `Surface` 画的图形。

## ⚠️ 本章易错点

1. 忘记 `pygame.init()` 或 `pygame.display.set_mode()`。
2. 忘记 `pygame.display.flip()` / `update()`，窗口黑屏。
3. 事件循环里不处理 `QUIT`，窗口关不掉。
4. 用 `KEYDOWN` 做持续移动，导致只能一格一格动。
5. `clock.tick()` 不设置，动画速度因电脑而异。
6. `blit` 的位置用 `(x, y)`，却传了 `Rect` 的宽高。
7. 先检测碰撞再更新位置，或反过来，导致判定不准。
8. 精灵移出屏幕后不 `kill()`，列表越来越长，游戏变卡。
9. 中文字体没设置，文字显示成方框。
10. `pygame.quit()` 后继续操作 Surface，报错。
