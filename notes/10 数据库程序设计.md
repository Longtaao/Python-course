## 10.1 数据库技术概述

### 几个基本概念

| 概念 | 通俗解释 |
| --- | --- |
| 数据库 | 存放数据的文件/系统 |
| 表（table） | 一张二维表，有行有列 |
| 行（record） | 一条记录，如一个学生 |
| 列（field） | 一个字段，如姓名、成绩 |
| 主键（primary key） | 唯一标识一行的字段，如学号 |
| 外键（foreign key） | 指向另一张表的主键，用来建立关系 |

### SQLite 的特点

- **无需安装服务器**，一个 `.db` 文件就是一个数据库。
- 零配置、轻量、跨平台，Python 标准库自带 `sqlite3`。
- 适合桌面应用、教学、小型项目；不适合高并发大型系统。
- 支持大部分标准 SQL。

### SQL 基本语法（先会这五句）

```sql
-- 建表
CREATE TABLE students (
    id    INTEGER PRIMARY KEY AUTOINCREMENT,
    name  TEXT NOT NULL,
    score REAL
);

-- 插入
INSERT INTO students (name, score) VALUES ('小明', 90);

-- 查询
SELECT * FROM students WHERE score >= 60 ORDER BY score DESC;

-- 更新
UPDATE students SET score = 95 WHERE name = '小明';

-- 删除
DELETE FROM students WHERE id = 1;
```

> [!NOTE]
> **SQL 不区分大小写**
> `SELECT` 和 `select` 一样；但字符串值区分。习惯上关键字大写、表名列名小写。

### 常用查询子句

```sql
SELECT name, score
FROM students
WHERE score >= 60          -- 条件
ORDER BY score DESC        -- 排序
LIMIT 10;                  -- 只取前 10 条

SELECT class, AVG(score) AS avg_score
FROM students
GROUP BY class             -- 分组
HAVING AVG(score) > 80;    -- 分组后筛选
```

| 运算符 | 含义 |
| --- | --- |
| `=` `<>` `>` `<` `>=` `<=` | 比较 |
| `AND` `OR` `NOT` | 逻辑 |
| `LIKE '%张%'` | 模糊匹配 |
| `IN (1, 2, 3)` | 在集合中 |
| `BETWEEN 60 AND 100` | 区间 |
| `IS NULL` / `IS NOT NULL` | 判空 |

聚合函数：`COUNT()`、`SUM()`、`AVG()`、`MAX()`、`MIN()`。

## 10.2 SQLite 程序设计

### 连接与建表

```python
import sqlite3

conn = sqlite3.connect("school.db")   # 文件不存在会自动创建
cur = conn.cursor()

cur.execute("""
CREATE TABLE IF NOT EXISTS students (
    id    INTEGER PRIMARY KEY AUTOINCREMENT,
    name  TEXT NOT NULL,
    score REAL
)
""")

conn.commit()
conn.close()
```

- `connect()` 只是连接/创建文件，**建表语句要执行**。
- `commit()` 提交事务，不提交的话数据可能不会真正写入。
- `close()` 关闭连接。

### 插入数据

```python
conn = sqlite3.connect("school.db")
cur = conn.cursor()

# 插入一条，用 ? 占位
cur.execute(
    "INSERT INTO students (name, score) VALUES (?, ?)",
    ("小明", 90)
)

# 插入多条
data = [("小红", 95), ("小刚", 78), ("小丽", 88)]
cur.executemany(
    "INSERT INTO students (name, score) VALUES (?, ?)",
    data
)

conn.commit()
conn.close()
```

> [!WARNING]
> **永远不要用 f-string 拼 SQL**
> ```python
> # ❌ 危险：SQL 注入
> cur.execute(f"SELECT * FROM students WHERE name = '{name}'")
> ```
> 如果 `name` 是 `' OR '1'='1`，条件永远成立，整张表都会被查出来。
> 正确做法是用 `?` 占位，让驱动负责转义。

### 查询数据

```python
conn = sqlite3.connect("school.db")
cur = conn.cursor()

cur.execute("SELECT id, name, score FROM students WHERE score >= ?", (80,))

rows = cur.fetchall()       # 返回列表，每行一个元组
for row in rows:
    print(row)

one = cur.fetchone()        # 只取一条
some = cur.fetchmany(3)     # 取三条

conn.close()
```

只取一条时：

```python
cur.execute("SELECT * FROM students WHERE id = ?", (1,))
row = cur.fetchone()
if row:
    print(row)
else:
    print("没有找到")
```

### 让查询结果像字典

```python
conn = sqlite3.connect("school.db")
conn.row_factory = sqlite3.Row   # 关键

cur = conn.cursor()
cur.execute("SELECT * FROM students")
for row in cur.fetchall():
    print(row["name"], row["score"])
```

### 更新与删除

```python
conn = sqlite3.connect("school.db")
cur = conn.cursor()

cur.execute("UPDATE students SET score = ? WHERE name = ?", (98, "小明"))
cur.execute("DELETE FROM students WHERE score < ?", (60,))

print("影响行数：", cur.rowcount)

conn.commit()
conn.close()
```

### 事务：一组操作要么全成功，要么全失败

```python
conn = sqlite3.connect("bank.db")

try:
    with conn:                     # 成功自动 commit，异常自动 rollback
        conn.execute("UPDATE accounts SET balance = balance - 100 WHERE id = 1")
        conn.execute("UPDATE accounts SET balance = balance + 100 WHERE id = 2")
except sqlite3.Error as e:
    print("转账失败：", e)
finally:
    conn.close()
```

`with conn:` 管理的不是关闭连接，而是**事务**。

### 用 pandas 读数据库（拓展）

```python
import pandas as pd
import sqlite3

conn = sqlite3.connect("school.db")
df = pd.read_sql("SELECT * FROM students", conn)
print(df)
conn.close()
```

数据量大、要做分析时，pandas 比手写游标方便。

## 10.3 综合案例：学生成绩管理

把 CRUD 封装成函数，结构清楚，也方便接 GUI。

```python
import sqlite3
from contextlib import contextmanager

DB = "students.db"

@contextmanager
def db():
    """连接数据库；正常结束提交，出错回滚，最后一定关闭。"""
    conn = sqlite3.connect(DB)
    conn.row_factory = sqlite3.Row
    try:
        yield conn
        conn.commit()
    except Exception:
        conn.rollback()
        raise
    finally:
        conn.close()

def init_db():
    with db() as conn:
        conn.execute("""
            CREATE TABLE IF NOT EXISTS students (
                id    INTEGER PRIMARY KEY AUTOINCREMENT,
                name  TEXT NOT NULL,
                score REAL NOT NULL
            )
        """)

def add_student(name, score):
    with db() as conn:
        conn.execute(
            "INSERT INTO students (name, score) VALUES (?, ?)",
            (name, score)
        )

def list_students():
    with db() as conn:
        rows = conn.execute(
            "SELECT id, name, score FROM students ORDER BY score DESC"
        ).fetchall()
    return [dict(row) for row in rows]

def update_score(student_id, score):
    with db() as conn:
        conn.execute(
            "UPDATE students SET score = ? WHERE id = ?",
            (score, student_id)
        )

def delete_student(student_id):
    with db() as conn:
        conn.execute("DELETE FROM students WHERE id = ?", (student_id,))

def average_score():
    with db() as conn:
        row = conn.execute("SELECT AVG(score) FROM students").fetchone()
    return row[0]
```

使用：

```python
init_db()
add_student("小明", 90)
add_student("小红", 95)

for s in list_students():
    print(s)

print("平均分：", average_score())
```

> [!TIP]
> **分层思路**
> 界面层（tkinter）只负责收集输入、显示结果；数据层（这些函数）负责 SQL。两层分开，换界面不用改数据库代码。

### 图形化管理工具

- **DB Browser for SQLite**：免费开源，可视化建表、查询、导入导出。
- **DataGrip / DBeaver**：功能更强，支持多种数据库。
- 命令行：`sqlite3 school.db`，然后输入 `.tables`、`.schema` 等。

## ⚠️ 本章易错点

1. 执行 `INSERT` / `UPDATE` / `DELETE` 后忘记 `commit()`，数据没保存。
2. 用 f-string 拼 SQL，造成 SQL 注入。
3. 查询参数写成 `execute(sql, name)`，第二个参数必须是**元组或列表**：`(name,)`。
4. 单元素元组忘记逗号：`(name)` 不是元组。
5. 忘记 `close()`，占用文件；用 `with` 或 `finally`。
6. 数据库文件被其他程序占用，报 `database is locked`。
7. `CREATE TABLE` 没加 `IF NOT EXISTS`，重复运行报错。
8. `fetchall()` 返回元组列表，不是字典；需要列名就设 `row_factory`。
9. `LIKE` 的 `%` 和 `_` 是通配符，搜索包含 `%` 的文本要转义。
10. 主键重复插入报 `UNIQUE constraint failed`。

## 🧪 小练习

```python
import sqlite3

conn = sqlite3.connect(":memory:")   # 内存数据库，程序结束就没了
cur = conn.cursor()

cur.execute("CREATE TABLE books (id INTEGER PRIMARY KEY, title TEXT, price REAL)")
cur.executemany(
    "INSERT INTO books (title, price) VALUES (?, ?)",
    [("Python 入门", 59.0), ("数据结构", 45.5), ("算法图解", 69.0)]
)
conn.commit()

cur.execute("SELECT title FROM books WHERE price > ? ORDER BY price DESC", (50,))
print(cur.fetchall())

conn.close()
```
