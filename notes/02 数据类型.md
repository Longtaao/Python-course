
# 02 数据类型

> **一句话：** Python 的六大常用类型——数值、字符串、列表、元组、字典、集合；**可变与不可变**是理解它们的总开关。

## 🗺️ 本章地图

| 类型 | 写法 | 可变？ | 有序？ | 典型用途 |
| --- | --- | --- | --- | --- |
| `int` / `float` | `10`, `3.14` | 不可变 | — | 计算 |
| `str` | `"hello"` | 不可变 | 有序 | 文本 |
| `list` | `[1, 2, 3]` | **可变** | 有序 | 一排数据 |
| `tuple` | `(1, 2, 3)` | 不可变 | 有序 | 不想被改的一组值 |
| `dict` | `{"name": "Tom"}` | **可变** | 有序（3.7+） | 键值查找 |
| `set` | `{1, 2, 3}` | **可变** | 无序 | 去重、集合运算 |

> [!TIP]
> **一句话选型**
> 一串有序数据用 `list`；不想被修改用 `tuple`；按名字查值用 `dict`；只关心「有没有、去重」用 `set`。

## 2.1 数值

### 整数 int

Python 的整数**没有大小上限**（受内存限制），可以直接算超大数：

```python
print(2 ** 100)          # 1267650600228229401496703205376
print(1_000_000)         # 1000000，下划线只是方便阅读
print(0b1010, 0o17, 0xFF)  # 二进制 10、八进制 15、十六进制 255
```

### 浮点数 float

浮点数按 IEEE 754 双精度存储，**不是所有小数都能精确表示**：

```python
print(0.1 + 0.2)              # 0.30000000000000004
print(0.1 + 0.2 == 0.3)       # False
```

处理办法：

```python
import math
from decimal import Decimal

print(round(0.1 + 0.2, 2))            # 0.3
print(math.isclose(0.1 + 0.2, 0.3))   # True，推荐比较浮点数
print(Decimal("0.1") + Decimal("0.2"))  # 0.3，金融计算用 Decimal
```

> [!WARNING]
> **永远不要用 `==` 直接比较两个浮点数**
> 用 `math.isclose(a, b)`，或比较它们的差是否小于一个很小的数。

### 复数 complex

```python
z = 3 + 4j
print(z.real, z.imag)   # 3.0 4.0
print(abs(z))           # 5.0
```

工程计算之外很少用，知道写法即可。

### 布尔 bool

`True` / `False`，本质是整数的子类：

```python
print(True + True)      # 2
print(isinstance(True, int))  # True
```

**哪些值会被当成 False？**

```text
False, None, 0, 0.0, "", [], (), {}, set()
```

其余基本都是 `True`。所以 `if my_list:` 等价于「列表非空」。

### 类型查看与转换

```python
print(type(3))                 # <class 'int'>
print(isinstance(3, int))      # True，推荐用 isinstance

print(int("123"))              # 123
print(int(3.9))                # 3，直接截断，不四舍五入
print(float("3.14"))           # 3.14
print(str(123))                # "123"
print(bool(""))                # False
```

## 2.2 字符串 str

### 定义与不可变性

```python
s1 = 'hello'
s2 = "hello"
s3 = """可以
跨多行"""
```

字符串**不可变**：所有「修改」方法都是返回一个新字符串，原串不变。

```python
s = "hello"
s.upper()
print(s)          # hello，原串没变
s = s.upper()     # 要重新赋值
print(s)          # HELLO
```

### 下标与切片

```python
s = "Python"
#    012345
#   -6-5-4-3-2-1
print(s[0])       # P
print(s[-1])      # n
print(s[1:4])     # yth，含头不含尾
print(s[:3])      # Pyt
print(s[3:])      # hon
print(s[::2])     # Pto
print(s[::-1])    # nohtyP，反转
```

切片规则：`s[start:stop:step]`，**包含 start，不包含 stop**，越界不报错。

### 常用方法

| 方法 | 作用 | 例子 |
| --- | --- | --- |
| `len(s)` | 长度 | `len("abc")` → `3` |
| `s.upper()` / `s.lower()` | 转大写/小写 | `"Ab".lower()` → `"ab"` |
| `s.strip()` | 去两端空白 | `" a ".strip()` → `"a"` |
| `s.split(sep)` | 按分隔符切分 | `"a,b".split(",")` → `['a','b']` |
| `sep.join(seq)` | 拼接 | `"-".join(["a","b"])` → `"a-b"` |
| `s.replace(old, new)` | 替换 | `"aba".replace("a","x")` |
| `s.find(sub)` | 查找，找不到返回 `-1` | `"abc".find("b")` → `1` |
| `s.index(sub)` | 查找，找不到报错 | — |
| `s.count(sub)` | 出现次数 | — |
| `s.startswith(prefix)` | 是否以…开头 | — |
| `s.endswith(suffix)` | 是否以…结尾 | — |
| `s.isdigit()` | 是否全是数字 | `"123".isdigit()` → `True` |

```python
text = "  Python is easy  "
print(text.strip())                 # "Python is easy"
print(text.strip().split())         # ['Python', 'is', 'easy']
print(",".join(["a", "b", "c"]))    # a,b,c
```

### 格式化输出（三种写法）

```python
name, age = "小明", 18

# 1. f-string（推荐，Python 3.6+）
print(f"{name}今年{age}岁")

# 2. format()
print("{}今年{}岁".format(name, age))

# 3. % 格式化（老写法）
print("%s今年%d岁" % (name, age))
```

f-string 常用格式：

```python
pi = 3.1415926
print(f"{pi:.2f}")      # 3.14，保留两位小数
print(f"{1234567:,}")   # 1,234,567，千分位
print(f"{'hi':>10}")    # 右对齐，宽度 10
print(f"{'hi':<10}|")   # 左对齐
print(f"{'hi':^10}|")   # 居中
print(f"{0.25:.1%}")    # 25.0%
```

## 2.3 列表 list

列表是**有序、可变**的容器，元素类型可以不同。

### 创建与访问

```python
nums = [1, 2, 3, 4, 5]
mixed = [1, "a", True, [2, 3]]

print(nums[0], nums[-1])    # 1 5
print(nums[1:3])            # [2, 3]
print(len(nums))            # 5
```

### 添加元素

```python
nums = [1, 2]

nums.append(3)          # 末尾加一个：[1, 2, 3]
nums.extend([4, 5])     # 末尾加多个：[1, 2, 3, 4, 5]
nums.insert(1, 99)      # 在索引 1 处插入：[1, 99, 2, 3, 4, 5]
nums = nums + [6]       # 拼接，产生新列表
```

> [!WARNING]
> **`append` vs `extend`**
> `append([4, 5])` 会把整个列表当成**一个元素**放进去，得到 `[1, 2, [4, 5]]`；`extend([4, 5])` 才是逐个加入。

### 修改与删除

```python
nums = [10, 20, 30, 20]

nums[0] = 99            # 修改
del nums[1]             # 按索引删除
nums.remove(20)         # 按值删除第一个 20
last = nums.pop()       # 删除并返回最后一个
first = nums.pop(0)     # 删除并返回指定索引
nums.clear()            # 清空
```

- `remove(x)`：值不存在会报 `ValueError`。
- `pop()`：列表为空会报 `IndexError`。

### 查找与统计

```python
nums = [10, 20, 30, 20]
print(20 in nums)           # True
print(nums.index(20))       # 1，第一个 20 的位置
print(nums.count(20))       # 2
```

### 排序与反转

```python
nums = [3, 1, 2]

nums.sort()                 # 原地排序，返回 None
print(nums)                 # [1, 2, 3]

nums.sort(reverse=True)     # 降序
print(sorted(nums))         # sorted 返回新列表，原列表不变
nums.reverse()              # 反转
```

对复杂数据按规则排序：

```python
students = [("Tom", 90), ("Amy", 95), ("Bob", 80)]
students.sort(key=lambda x: x[1], reverse=True)
print(students)   # [('Amy', 95), ('Tom', 90), ('Bob', 80)]
```

### 列表推导式

```python
squares = [x ** 2 for x in range(1, 6)]        # [1, 4, 9, 16, 25]
evens = [x for x in range(10) if x % 2 == 0]   # [0, 2, 4, 6, 8]
```

比手写循环更短、更快，但**别嵌套太深**，两层以上就考虑拆开写。

## 2.4 元组 tuple

元组是**不可变**的有序序列，创建后不能增删改。

```python
t = (1, 2, 3)
print(t[0])       # 1
# t[0] = 99       # ❌ TypeError
```

### 两个语法坑

```python
a = (1)       # 这是整数 1，不是元组
b = (1,)      # 单元素元组，必须带逗号
c = 1, 2, 3   # 不加括号也是元组
```

### 解包

```python
point = (3, 5)
x, y = point
print(x, y)          # 3 5

a, b = b, a          # 交换变量，本质是元组解包

first, *rest = [1, 2, 3, 4]
print(first, rest)   # 1 [2, 3, 4]
```

### 为什么需要元组

- 数据不希望被意外修改（如坐标、配置）。
- 元组可哈希，能当**字典的键**或**集合的元素**。
- 函数返回多个值，本质就是返回元组。

```python
def min_max(nums):
    return min(nums), max(nums)

lo, hi = min_max([3, 1, 4, 1, 5])
```

## 2.5 字典 dict

字典存的是**键值对**，通过键快速查找值。

```python
student = {"name": "小明", "age": 18, "score": 92}
```

### 访问与增改

```python
print(student["name"])            # 小明
print(student.get("height"))      # None，键不存在不报错
print(student.get("height", 170)) # 170，给默认值

student["age"] = 19               # 修改
student["height"] = 175           # 新增
student.update({"score": 95, "city": "北京"})  # 批量更新/新增
```

> [!TIP]
> **用 `get()` 还是 `[]`？**
> 确定键存在用 `[]`；不确定或想给默认值用 `get()`。直接 `student["height"]` 在键不存在时会抛 `KeyError`。

### 删除

```python
del student["city"]                  # 按 key 删除
score = student.pop("score")         # 删除并返回值
student.pop("nothing", "默认值")      # 不存在时返回默认值，不报错
student.clear()                      # 清空
```

### 遍历

```python
student = {"name": "小明", "age": 18}

for key in student:                  # 遍历键
    print(key)

for value in student.values():       # 遍历值
    print(value)

for key, value in student.items():   # 同时遍历键值（最常用）
    print(key, value)
```

### 字典推导式

```python
squares = {x: x ** 2 for x in range(1, 6)}
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# 统计词频
words = ["a", "b", "a", "c", "a"]
count = {}
for w in words:
    count[w] = count.get(w, 0) + 1
print(count)   # {'a': 3, 'b': 1, 'c': 1}
```

> [!NOTE]
> **键的规则**
> 键必须**不可变且可哈希**：数字、字符串、元组可以；列表、字典、集合不行。
> Python 3.7 起字典**保留插入顺序**，但不要依赖它做排序，需要顺序请显式 `sorted()`。

## 2.6 集合 set

集合是**无序、不重复**的容器，最适合去重和集合运算。

```python
s = {1, 2, 3, 3, 2}
print(s)          # {1, 2, 3}，自动去重

empty = set()     # 空集合必须这样写
# empty = {}      # ❌ 这是空字典
```

### 增删

```python
s = {1, 2}
s.add(3)          # 添加
s.discard(2)      # 删除，不存在不报错
s.remove(1)       # 删除，不存在报 KeyError
s.clear()         # 清空
```

### 集合运算

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)      # {1, 2, 3, 4, 5} 并集
print(a & b)      # {3}             交集
print(a - b)      # {1, 2}          差集
print(a ^ b)      # {1, 2, 4, 5}    对称差（只在一边出现）
print(a.issubset({1, 2, 3, 4}))   # True，子集
```

### 典型用途

```python
# 去重（不保证顺序）
nums = [1, 2, 2, 3, 1]
unique = list(set(nums))

# 去重且保持原顺序
unique_ordered = list(dict.fromkeys(nums))

# 快速判断元素是否存在
if 3 in {1, 2, 3}:
    print("存在")
```

## 2.7 可变、不可变与拷贝（本章最重要）

### 哪些可变？

| 不可变 | 可变 |
| --- | --- |
| `int`、`float`、`bool`、`str`、`tuple` | `list`、`dict`、`set` |

不可变对象一旦创建，值就不能变；「修改」其实是创建了一个新对象。

```python
a = "hello"
b = a
a = a + " world"
print(a, b)   # hello world  hello
```

### 赋值的真相：标签，不是盒子

```python
a = [1, 2, 3]
b = a          # b 和 a 指向同一个列表
b.append(4)
print(a)       # [1, 2, 3, 4]，a 也变了！
```

想得到独立副本：

```python
a = [1, 2, 3]
b = a.copy()      # 或 a[:] 或 list(a)
b.append(4)
print(a)          # [1, 2, 3]
```

### 浅拷贝 vs 深拷贝

```python
import copy

a = [[1, 2], [3, 4]]
b = a.copy()          # 浅拷贝：外层新列表，内层还是同一批子列表
b[0].append(99)
print(a)              # [[1, 2, 99], [3, 4]]

c = copy.deepcopy(a)  # 深拷贝：里里外外全复制
c[0].append(100)
print(a)              # 不受影响
```

> [!TIP]
> **记忆法**
> 浅拷贝只复制「第一层抽屉」，抽屉里的盒子还是共用的；深拷贝连盒子里的东西一起复制。

### 函数传参也是「传标签」

```python
def add_item(lst):
    lst.append(4)

nums = [1, 2, 3]
add_item(nums)
print(nums)        # [1, 2, 3, 4]，原列表被修改

def reassign(lst):
    lst = [9, 9]   # 只是让局部变量指向新列表

nums = [1, 2]
reassign(nums)
print(nums)        # [1, 2]，原列表没变
```

---

## ⚠️ 本章易错点

1. `b = a` 不是复制列表，改一个两个都变。
2. 嵌套列表的 `.copy()` 只是浅拷贝。
3. `sort()` 原地排序返回 `None`，写 `a = a.sort()` 会把 `a` 变成 `None`。
4. `append` 加一个元素，`extend` 加一串元素。
5. 单元素元组必须写 `(1,)`。
6. 空集合写 `set()`，`{}` 是空字典。
7. 字典的键不能用列表。
8. 遍历列表时删除元素会漏项，应遍历副本或倒序删除。
9. 字符串方法不改变原串，要重新赋值。
10. `0.1 + 0.2 != 0.3`，浮点数比较用 `math.isclose`。

## 🧪 小练习

```python
# 1. 统计一段文本的词频，输出前 3 名
text = "the quick brown fox jumps over the lazy dog the fox"
count = {}
for word in text.split():
    count[word] = count.get(word, 0) + 1

top3 = sorted(count.items(), key=lambda x: x[1], reverse=True)[:3]
print(top3)

# 2. 列表去重并保持顺序
nums = [3, 1, 3, 2, 1]
unique = list(dict.fromkeys(nums))
print(unique)   # [3, 1, 2]

# 3. 用字典表示学生，按成绩排序
students = [
    {"name": "Tom", "score": 90},
    {"name": "Amy", "score": 95},
]
students.sort(key=lambda s: s["score"], reverse=True)
print(students)
```
