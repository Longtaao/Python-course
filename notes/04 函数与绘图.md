## 4.1 标准函数

### 内置函数（不用导入）

```python
print(abs(-3))          # 3
print(max(1, 5, 2))     # 5
print(min([3, 1, 2]))   # 1
print(sum([1, 2, 3]))   # 6
print(len("hello"))     # 5
print(round(3.14159, 2))  # 3.14
print(pow(2, 10))       # 1024
print(sorted([3, 1, 2]))  # [1, 2, 3]
print(type(3), isinstance(3, int))
```

常用高阶函数（后面函数式编程还会讲）：

```python
nums = [1, 2, 3, 4]

print(list(map(lambda x: x * 2, nums)))       # [2, 4, 6, 8]
print(list(filter(lambda x: x % 2 == 0, nums)))  # [2, 4]
print(list(zip(["a", "b"], [1, 2])))          # [('a', 1), ('b', 2)]
print(list(enumerate(["a", "b"])))            # [(0, 'a'), (1, 'b')]
```

### 模块函数

```python
import math
print(math.sqrt(16))      # 4.0
print(math.pi)            # 3.141592653589793

from random import randint, choice
print(randint(1, 10))
print(choice(["石头", "剪刀", "布"]))
```

> [!TIP]
> **怎么知道有哪些函数**
> `dir(math)` 看全部名字，`help(math.sqrt)` 看具体用法。IDE 里输入 `math.` 通常会自动提示。

## 4.2 自定义函数

### 定义与调用

```python
def greet(name):
    """向指定的人打招呼。"""     # 文档字符串，可选
    return f"你好，{name}！"

msg = greet("小明")
print(msg)      # 你好，小明！
```

- `def` 定义，函数名后必须有括号和冒号。
- 函数体缩进。
- `return` 结束函数并返回结果；没有 `return` 时返回 `None`。

### 返回值

```python
def add(a, b):
    return a + b

def min_max(nums):
    return min(nums), max(nums)     # 实际返回一个元组

lo, hi = min_max([3, 1, 5])
```

一个函数可以有多条 `return`，执行到第一条就返回：

```python
def check(score):
    if score < 0 or score > 100:
        return "分数不合法"
    if score >= 60:
        return "及格"
    return "不及格"
```

这种「提前返回」能减少嵌套，代码更清楚。

### 参数的种类

```python
def show(name, age=18, *args, **kwargs):
    print(name, age, args, kwargs)

show("Tom")                          # Tom 18 () {}
show("Tom", 20)                      # Tom 20 () {}
show("Tom", 20, "a", "b", x=1, y=2)  # Tom 20 ('a','b') {'x':1,'y':2}
```

| 参数 | 写法 | 说明 |
| --- | --- | --- |
| 位置参数 | `def f(a, b)` | 按顺序传 |
| 关键字参数 | `f(b=2, a=1)` | 按名字传，顺序随意 |
| 默认参数 | `def f(a, b=10)` | 不传就用默认值，默认参数放后面 |
| 可变位置参数 | `*args` | 收集成元组 |
| 可变关键字参数 | `**kwargs` | 收集成字典 |

### ⚠️ 默认参数的大坑

```python
# 错误写法
def add_item(item, lst=[]):
    lst.append(item)
    return lst

print(add_item(1))   # [1]
print(add_item(2))   # [1, 2]  ← 不是 [2]！
```

默认值**只在函数定义时创建一次**，之后所有调用共用同一个列表。

正确写法：

```python
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
```

> [!WARNING]
> **这条几乎必考**
> 默认参数不要用可变对象（列表、字典、集合），用 `None` 占位再在函数内创建。

### 局部变量与全局变量

```python
x = 10              # 全局变量

def f():
    x = 20          # 局部变量，和全局的 x 不是同一个
    print(x)        # 20

f()
print(x)            # 10
```

在函数里**读取**全局变量可以直接读；要**修改**，需要 `global`：

```python
count = 0

def increase():
    global count
    count += 1

increase()
print(count)        # 1
```

> [!TIP]
> **少用 global**
> 全局变量让程序难以调试。更好的做法是把值作为参数传入、用返回值传出。

### 自定义模块

一个 `.py` 文件就是一个模块。

```python
# mymath.py
def square(x):
    return x * x

PI = 3.14159
```

```python
# main.py
import mymath
print(mymath.square(5))
print(mymath.PI)

from mymath import square
print(square(3))
```

模块被导入时会执行顶层代码，所以常加入口判断：

```python
# mymath.py
def square(x):
    return x * x

if __name__ == "__main__":
    # 只有直接运行 mymath.py 时才执行
    print(square(4))
```

`__name__` 在被直接运行时是 `"__main__"`，被导入时是模块名。

## 4.3 迭代与递归

### 迭代：用循环反复推进

迭代就是「用上一次的结果算下一次」，靠循环完成。

```python
def factorial_iter(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

print(factorial_iter(5))   # 120
```

斐波那契（迭代版）：

```python
def fib_iter(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

### 递归：函数调用自己

递归必须有两个部分：

1. **终止条件（base case）**：什么时候不再调用自己。
2. **递推关系**：把大问题拆成同类的更小问题。

```python
def factorial(n):
    if n == 0 or n == 1:     # 终止条件
        return 1
    return n * factorial(n - 1)   # 递推

print(factorial(5))          # 120
```

执行过程：

```text
factorial(5)
= 5 * factorial(4)
= 5 * 4 * factorial(3)
= 5 * 4 * 3 * factorial(2)
= 5 * 4 * 3 * 2 * factorial(1)
= 120
```

斐波那契（递归版）：

```python
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)
```

这个写法直观但**非常慢**：`fib(30)` 会重复计算大量子问题。加缓存：

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)
```

### 迭代 vs 递归

| | 迭代 | 递归 |
| --- | --- | --- |
| 写法 | 循环 | 函数自调用 |
| 可读性 | 直白 | 贴近数学定义，树/图问题更自然 |
| 性能 | 通常更好 | 有函数调用开销，可能栈溢出 |
| 风险 | 死循环 | 缺终止条件 / 递归太深 |

Python 默认递归深度约 1000 层：

```python
import sys
print(sys.getrecursionlimit())
# sys.setrecursionlimit(5000)   # 可以调大，但不建议依赖
```

> [!TIP]
> **选择原则**
> 能用循环就用循环；问题本身是树形/分治结构（如汉诺塔、目录遍历）时，递归更自然。

## 4.4 案例：蒙特卡洛法求 π

思路：往边长为 2 的正方形里随机撒点，落在内切圆（半径 1）里的比例约为 π/4。

```python
import random

def monte_carlo_pi(n):
    hits = 0
    for _ in range(n):
        x = random.random() * 2 - 1    # [-1, 1)
        y = random.random() * 2 - 1
        if x * x + y * y <= 1:
            hits += 1
    return 4 * hits / n

for n in [1000, 10000, 100000, 1000000]:
    print(n, monte_carlo_pi(n))
```

- 点越多越接近 π，但**不是严格单调变准**，每次结果有随机波动。
- 这是「用随机模拟解决确定问题」的典型例子。
- 同样的思路可以推广到求定积分、模拟排队等。

## 4.5 turtle 绘图

`turtle` 是 Python 自带的海龟绘图库，适合入门和演示算法。

### 基本套路

```python
import turtle

t = turtle.Turtle()      # 创建海龟
t.speed(5)               # 速度 0-10，0 最快

t.forward(100)           # 前进 100
t.right(90)              # 右转 90 度
t.forward(100)

turtle.done()            # 保持窗口，别让程序立刻退出
```

### 常用函数

| 函数 | 作用 |
| --- | --- |
| `forward(d)` / `fd(d)` | 前进 |
| `backward(d)` / `bk(d)` | 后退 |
| `left(a)` / `right(a)` | 左转/右转（角度） |
| `goto(x, y)` | 移动到坐标 |
| `circle(r)` | 画半径为 r 的圆 |
| `penup()` / `pendown()` | 抬笔/落笔 |
| `pencolor(c)` / `fillcolor(c)` | 画笔色/填充色 |
| `begin_fill()` / `end_fill()` | 开始/结束填充 |
| `setheading(a)` | 设置朝向 |
| `hideturtle()` | 隐藏海龟 |
| `write(text)` | 写文字 |

### 案例 1：正方形

```python
import turtle

t = turtle.Turtle()
for _ in range(4):
    t.forward(100)
    t.left(90)

turtle.done()
```

### 案例 2：正多边形

```python
import turtle

n = 6
t = turtle.Turtle()
for _ in range(n):
    t.forward(80)
    t.left(360 / n)

turtle.done()
```

外角 = 360° / 边数。

### 案例 3：五角星

```python
import turtle

t = turtle.Turtle()
t.fillcolor("gold")
t.begin_fill()
for _ in range(5):
    t.forward(150)
    t.right(144)
t.end_fill()

turtle.done()
```

### 案例 4：正弦曲线

```python
import turtle
import math

t = turtle.Turtle()
t.penup()
t.goto(-300, 0)
t.pendown()

for x in range(-300, 301):
    y = 100 * math.sin(x / 50)
    t.goto(x, y)

turtle.done()
```

### 案例 5：科赫雪花（分形）

```python
import turtle

def koch(t, length, depth):
    if depth == 0:
        t.forward(length)
        return
    length /= 3
    koch(t, length, depth - 1)
    t.left(60)
    koch(t, length, depth - 1)
    t.right(120)
    koch(t, length, depth - 1)
    t.left(60)
    koch(t, length, depth - 1)

t = turtle.Turtle()
t.speed(0)
koch(t, 300, 4)
turtle.done()
```

分形 = 局部和整体长得像。递归深度每加一层，细节多一级。

## 4.6 案例：随机生成姓名

从《唐诗》和《百家姓》里各取字组合：

```python
import random

surnames = list("赵钱孙李周吴郑王冯陈褚卫蒋沈韩杨")
given_chars = list("明月清风山水云竹松梅兰菊江河海洋")

def make_name():
    return random.choice(surnames) + "".join(
        random.choice(given_chars) for _ in range(2)
    )

for _ in range(5):
    print(make_name())
```

重点是「**把数据准备好 + 随机选择 + 字符串拼接**」这个套路，换成别的素材也一样。

## ⚠️ 本章易错点

1. 默认参数用了可变对象，导致多次调用共享数据。
2. 函数没有 `return`，结果默认是 `None`。
3. 在函数里修改全局变量忘记 `global`。
4. 递归没有终止条件，导致 `RecursionError`。
5. 递归层数太深（超过约 1000 层）。
6. 模块名和标准库重名，导入到错误的模块。
7. 忘记 `turtle.done()`，窗口一闪而过。
8. `turtle.circle(r)` 画的是圆，不是填充圆；填充要先 `begin_fill()`。
9. 函数名和变量名重复，后定义的会覆盖前面的。
10. 参数顺序写错，尤其是默认参数放在非默认参数前面（语法错误）。

## 🧪 小练习

```python
# 1. 判断回文
def is_palindrome(s):
    s = s.replace(" ", "").lower()
    return s == s[::-1]

# 2. 递归求幂
def power(base, exp):
    if exp == 0:
        return 1
    return base * power(base, exp - 1)

# 3. 用 turtle 画同心圆
import turtle
t = turtle.Turtle()
for r in range(20, 120, 20):
    t.penup()
    t.goto(0, -r)
    t.pendown()
    t.circle(r)
turtle.done()
```
