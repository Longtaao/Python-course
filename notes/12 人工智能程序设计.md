## 12.1 机器学习基本概念

### 用一句话区分

| 类型 | 有没有标签 | 任务 | 例子 |
| --- | --- | --- | --- |
| 监督学习 · 分类 | 有，离散 | 判断类别 | 垃圾邮件识别、花的品种 |
| 监督学习 · 回归 | 有，连续 | 预测数值 | 房价、销量 |
| 无监督学习 · 聚类 | 无 | 分组 | 用户分群、城市分级 |

### 基本术语

```text
样本（sample）：一行数据，如一个病人
特征（feature）：用来判断的依据，如年龄、肿瘤大小
标签（label）：要预测的答案，如良性/恶性
模型（model）：从特征到标签的映射函数
训练（fit）：用数据调整模型参数
预测（predict）：对新样本输出结果
```

### 训练集、验证集、测试集

```text
全部数据
├── 训练集（约 60-80%）：用来训练模型
├── 验证集（可选）：调参数、选模型
└── 测试集（约 20%）：最后评估，不能参与训练
```

> [!WARNING]
> **测试集不能偷看**
> 如果用测试集调参，模型就「见过答案」了，评估结果会虚高。这叫**数据泄露**。

### 过拟合与欠拟合

| 现象 | 表现 | 原因 | 对策 |
| --- | --- | --- | --- |
| 欠拟合 | 训练集和测试集都差 | 模型太简单 | 增加特征、换更复杂模型 |
| 过拟合 | 训练集很好，测试集差 | 模型太复杂/数据太少 | 更多数据、正则化、简化模型、交叉验证 |

**泛化能力**：模型对没见过的数据表现好，才是真的好。

### 神经网络与深度学习（了解）

```text
输入层 → 隐藏层（可多层）→ 输出层
每个连接有权重，每个神经元有激活函数
训练 = 不断调整权重，让预测误差变小
```

- **深度学习** = 多隐藏层的神经网络。
- 适合图像、语音、自然语言等复杂数据。
- 本章的 KNN、逻辑回归、SVM 属于**传统机器学习**，数据量不大时往往够用且更快。

## 12.2 数据预处理

### sklearn 数据集

```python
from sklearn.datasets import load_iris, load_breast_cancer, load_digits

iris = load_iris()
print(iris.data.shape)          # (150, 4)，150 个样本，4 个特征
print(iris.target.shape)        # (150,)
print(iris.feature_names)       # 特征名
print(iris.target_names)        # 类别名
print(iris.DESCR)               # 数据集说明
```

| 数据集 | 样本数 | 特征数 | 类别 | 任务 |
| --- | --- | --- | --- | --- |
| `load_iris` | 150 | 4 | 3 种鸢尾花 | 分类 |
| `load_breast_cancer` | 569 | 30 | 良性/恶性 | 二分类 |
| `load_digits` | 1797 | 64（8×8 像素） | 0–9 | 多分类 |

### 划分训练集与测试集

```python
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    iris.data,
    iris.target,
    test_size=0.2,        # 20% 做测试
    random_state=42,      # 固定随机种子，结果可复现
    stratify=iris.target  # 按类别比例分层，避免某类全进测试集
)
```

### 标准化

不同特征量纲差别大时（如身高 cm 和收入万元），需要标准化：

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

X_train = scaler.fit_transform(X_train)   # 在训练集上计算均值/方差并转换
X_test = scaler.transform(X_test)         # 用训练集的参数转换测试集
```

> [!WARNING]
> **顺序不能反**
> 先 `fit_transform` 训练集，再 `transform` 测试集。如果对测试集也 `fit_transform`，就把测试集信息泄露进训练过程了。

常见预处理：

| 方法 | 作用 |
| --- | --- |
| `StandardScaler` | 均值 0、方差 1（最常用） |
| `MinMaxScaler` | 缩放到 [0, 1] |
| `LabelEncoder` | 把类别字符串转成 0,1,2… |
| `OneHotEncoder` | 类别转独热向量 |
| `SimpleImputer` | 填补缺失值 |

## 12.3 三个入门模型

### KNN：K 近邻

**思路**：找离新样本最近的 K 个已知样本，投票决定类别。

```python
from sklearn.neighbors import KNeighborsClassifier

model = KNeighborsClassifier(n_neighbors=3)
model.fit(X_train, y_train)

pred = model.predict(X_test)
score = model.score(X_test, y_test)
```

- K 太小：对噪声敏感，容易过拟合。
- K 太大：把远处不相关的样本也算进来，容易欠拟合。
- 必须标准化，否则距离会被大数值特征主导。

### 逻辑回归 Logistic Regression

名字有「回归」，其实是**分类**模型，输出概率。

```python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression(max_iter=5000)
model.fit(X_train, y_train)

pred = model.predict(X_test)
prob = model.predict_proba(X_test)   # 每类的概率
```

- 适合线性可分或近似线性的二分类问题。
- `max_iter` 太小会提示未收敛，调大即可。

### SVM：支持向量机

**思路**：找一条「间隔最大」的分界线；线性分不开时，用核函数映射到高维。

```python
from sklearn.svm import SVC

model = SVC(kernel="rbf", C=1.0, gamma="scale")
model.fit(X_train, y_train)
pred = model.predict(X_test)
```

| 参数 | 作用 |
| --- | --- |
| `kernel` | `"linear"` 线性核、`"rbf"` 高斯核（默认） |
| `C` | 惩罚系数，越大越不容忍错误，容易过拟合 |
| `gamma` | RBF 核的影响范围，越大越关注局部，容易过拟合 |

SVM 对量纲敏感，也需要标准化。

### 评估指标

```python
from sklearn.metrics import (
    accuracy_score, confusion_matrix, classification_report
)

print("准确率：", accuracy_score(y_test, pred))
print("混淆矩阵：\n", confusion_matrix(y_test, pred))
print(classification_report(y_test, pred, target_names=iris.target_names))
```

| 指标 | 含义 |
| --- | --- |
| 准确率 Accuracy | 预测对的样本 / 总样本 |
| 精确率 Precision | 预测为正的里面，真正为正的比例 |
| 召回率 Recall | 真正为正的里面，被找出来的比例 |
| F1 | 精确率和召回率的调和平均 |

> [!WARNING]
> **准确率会骗人**
> 99% 的样本是负类时，全猜负类也有 99% 准确率。类别不平衡要看精确率、召回率、F1 和混淆矩阵。

### 交叉验证

```python
from sklearn.model_selection import cross_val_score

scores = cross_val_score(model, iris.data, iris.target, cv=5)
print(scores.mean(), scores.std())
```

把数据分成 5 份，轮流用 4 份训练、1 份验证，结果更稳定。

## 12.4 案例实战

### 案例 1：识别鸢尾花（KNN）

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score

iris = load_iris()

X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.2,
    random_state=42, stratify=iris.target
)

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

# 试试不同的 K
for k in [1, 3, 5, 7, 9]:
    model = KNeighborsClassifier(n_neighbors=k)
    model.fit(X_train, y_train)
    acc = accuracy_score(y_test, model.predict(X_test))
    print(f"K={k}, 准确率={acc:.3f}")
```

### 案例 2：预测乳腺癌（逻辑回归）

```python
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, confusion_matrix

data = load_breast_cancer()

X_train, X_test, y_train, y_test = train_test_split(
    data.data, data.target, test_size=0.2,
    random_state=42, stratify=data.target
)

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

model = LogisticRegression(max_iter=5000)
model.fit(X_train, y_train)
pred = model.predict(X_test)

print(confusion_matrix(y_test, pred))
print(classification_report(y_test, pred, target_names=data.target_names))
```

### 案例 3：识别手写数字（SVM）

```python
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score

digits = load_digits()
print(digits.images.shape)    # (1797, 8, 8)
print(digits.data.shape)      # (1797, 64)，每张图拉平成 64 个像素

X_train, X_test, y_train, y_test = train_test_split(
    digits.data, digits.target, test_size=0.2,
    random_state=42, stratify=digits.target
)

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

model = SVC(kernel="rbf")
model.fit(X_train, y_train)
print("准确率：", accuracy_score(y_test, model.predict(X_test)))
```

### 案例 4：把图片转成特征

模型只认数字，所以图片要先转成向量：

```python
from PIL import Image
import numpy as np

img = Image.open("digit.png").convert("L")   # 转灰度
img = img.resize((8, 8))                      # 缩放到 8×8
pixels = np.array(img).reshape(1, -1)         # 拉平成 1×64

pred = model.predict(pixels)
print("预测数字：", pred[0])
```

真实项目通常用 28×28（MNIST），并做二值化/去噪，让数字居中、笔画清晰。

## ⚠️ 本章易错点

1. 先标准化再划分数据集，造成数据泄露。
2. 对测试集调用 `fit_transform`，应该只 `transform`。
3. KNN/SVM 不标准化，结果很差。
4. 用准确率评估不平衡数据。
5. 不设 `random_state`，每次结果不同，无法复现。
6. 只用训练集评估，得到虚高分数。
7. 调参时反复用测试集，测试集就不再「干净」。
8. 特征里有 ID、姓名等无关列，干扰模型。
9. 类别标签是字符串时，某些模型不接受，需要编码。
10. 认为模型越复杂越好，忽略过拟合。
