
# 03 程序结构

## 3.1 顺序结构

程序默认从上到下、一条一条执行。顺序结构里最常见的是**导入、赋值、输入输出**。

### 导入语句

```python
import math                      # 导入整个模块
import numpy as np               # 起别名
from math import sqrt, pi        # 只导入需要的名字
from math import *               # 导入全部（不推荐，容易污染命名空间）
```

> [!TIP]
> **导入习惯**
> 标准库放最上面，第三方库其次，自己写的模块放最后，中间空一行。尽量别用 `from 模块 import *`。

### 赋值语句

```python
a = 10
x = y = z = 0                 # 链式赋值
p, q = 1, 2                   # 同时赋值
p, q = q, p                   # 交换
name, age = "小明", 18        # 解包赋值
first, *rest = [1, 2, 3, 4]   # 星号收集剩余
a += 1                        # 增量赋值：+= -= *= /= //= %= **=
```

### 输入 input()

```python
name = input("请输入姓名：")      # 返回值永远是 str
age = int(input("请输入年龄："))  # 要数字就转换

# 一行输入多个数
a, b = map(int, input("输入两个整数：").split())
nums = list(map(float, input("输入多个数：").split()))
```

> [!WARNING]
> **最常见的错误**
> `input()` 拿到的是字符串。`input("数字：") + 1` 会报 `TypeError`，必须先 `int()` 或 `float()`。

### 输出 print()

```python
print("hello")
print("a", "b", "c")                 # a b c，默认空格分隔
print("a", "b", sep="-")             # a-b
print("hello", end="")               # 不换行
print("world")                       # helloworld
print(f"{3.14159:.2f}")              # 3.14
```

## 3.2 选择结构

### 单条件 if

```python
score = 85
if score >= 60:
    print("及格")
```

注意冒号 `:` 和缩进，两样都不能少。

### 双条件 if-else

```python
if score >= 60:
    print("及格")
else:
    print("不及格")
```

### 多条件 if-elif-else

```python
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "E"
```

**从上往下判断，命中一个就跳出**，所以条件顺序很重要。

### 条件表达式（三元运算）

```python
result = "及格" if score >= 60 else "不及格"
```

适合简单的二选一，别嵌套太多层。

### 嵌套选择

```python
if score >= 60:
    if score >= 90:
        print("优秀")
    else:
        print("及格")
else:
    print("不及格")
```

嵌套超过三层就该考虑用 `elif`、提前 `return` 或拆函数。

### 条件写什么

`if` 后面只要是一个「真/假」的表达式即可：

```python
if name:             # 字符串非空
if nums:             # 列表非空
if not done:         # 布尔取反
if 0 <= x <= 100:    # 连续比较
if x == 1 or x == 2: # 逻辑组合
```

> [!WARNING]
> **`=` 和 `==`**
> `if x = 1:` 是语法错误（Python 3），赋值用 `=`，比较用 `==`。

### 经典例子：判断闰年

```python
year = int(input("年份："))
if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:
    print("闰年")
else:
    print("平年")
```

规则：**能被 4 整除但不能被 100 整除，或者能被 400 整除**。

## 3.3 循环结构

### 计数循环 for

`for` 用来遍历一个可迭代对象（列表、字符串、range 等）。

```python
for i in range(5):
    print(i)          # 0 1 2 3 4

for ch in "abc":
    print(ch)

for x in [10, 20, 30]:
    print(x)
```

### range() 的三种写法

```python
range(5)            # 0,1,2,3,4         含头不含尾
range(1, 6)         # 1,2,3,4,5
range(1, 10, 2)     # 1,3,5,7,9         步长为 2
range(5, 0, -1)     # 5,4,3,2,1         倒序
```

> [!WARNING]
> **不含尾**
> `range(1, 5)` 只到 4。想要 1 到 5，写 `range(1, 6)`。

### 条件循环 while

```python
i = 1
while i <= 5:
    print(i)
    i += 1        # 别忘了更新条件，否则死循环
```

什么时候用 `while`：

- 循环次数**不确定**，由条件决定（如「直到猜对为止」）。
- 需要反复读取输入、处理直到满足某个状态。

```python
# 猜数字
import random
answer = random.randint(1, 100)
while True:
    guess = int(input("猜一个 1-100 的数："))
    if guess == answer:
        print("猜对了！")
        break
    elif guess < answer:
        print("小了")
    else:
        print("大了")
```

### 中止与跳出

| 语句 | 作用 |
| --- | --- |
| `break` | 立即结束**当前这一层**循环 |
| `continue` | 跳过本次剩余代码，进入下一次循环 |
| `pass` | 什么也不做，占位 |

```python
for i in range(10):
    if i == 3:
        continue      # 跳过 3
    if i == 6:
        break         # 到 6 就停
    print(i)          # 0 1 2 4 5
```

### 循环的 else

`for` / `while` 可以带 `else`，**只有循环正常结束（没有被 break）时才执行**：

```python
for n in range(2, 10):
    for i in range(2, n):
        if n % i == 0:
            break
    else:
        print(n, "是质数")
```

这个 `else` 常用来判断「找没找到」。

### 循环嵌套

```python
# 九九乘法表
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i*j}", end="\t")
    print()
```

外层控制行，内层控制列。`break` 只跳出**最内层**循环；要一次跳出多层，可以用标志变量或函数 `return`。

### for 与 while 怎么选

| 场景 | 推荐 |
| --- | --- |
| 已知次数 / 遍历序列 | `for` |
| 次数未知 / 条件驱动 | `while` |
| 遍历同时需要下标 | `for i, x in enumerate(nums)` |
| 同时遍历两个序列 | `for a, b in zip(list1, list2)` |

## 3.4 案例：用 BBP 公式求 π

BBP 公式：

```text
π = Σ (1/16^k) × [4/(8k+1) − 2/(8k+4) − 1/(8k+5) − 1/(8k+6)]
```

```python
def bbp_pi(n):
    pi = 0.0
    for k in range(n):
        pi += (1 / 16 ** k) * (
            4 / (8 * k + 1)
            - 2 / (8 * k + 4)
            - 1 / (8 * k + 5)
            - 1 / (8 * k + 6)
        )
    return pi

for n in [10, 50, 100, 500]:
    print(n, f"{bbp_pi(n):.15f}")
```

- 项数越多，结果越接近 π。
- 这个公式每多算一项大约多得到一位十六进制精度，收敛很快。
- 注意：`/` 是真除法，不要写成 `//`。

## 🧩 综合小例

### 判断质数

```python
n = int(input("输入一个大于 1 的整数："))
is_prime = True
for i in range(2, int(n ** 0.5) + 1):
    if n % i == 0:
        is_prime = False
        break

print("质数" if is_prime else "合数")
```

只试到 `√n` 就够，因为因数成对出现。

### 求 1 到 100 的和

```python
total = 0
for i in range(1, 101):
    total += i
print(total)          # 5050

# 或者直接用内置函数
print(sum(range(1, 101)))
```

### 打印斐波那契数列前 20 项

```python
a, b = 0, 1
for _ in range(20):
    print(a, end=" ")
    a, b = b, a + b
```

## ⚠️ 本章易错点

1. `range(1, 5)` 不含 5。
2. `while` 里忘记更新循环变量，导致死循环。
3. `if x = 1` 是语法错误，比较用 `==`。
4. `break` 只跳出最内层循环。
5. 冒号后面没有缩进块，报 `IndentationError`。
6. 空代码块要用 `pass` 占位。
7. 遍历列表时删除元素会漏项：

```python
nums = [1, 2, 3, 4]
for x in nums[:]:      # 遍历副本
    if x % 2 == 0:
        nums.remove(x)
```

8. 浮点数判等用 `math.isclose`，不要用 `==`。
9. `input()` 得到字符串，比较数字前先转换。
10. 循环的 `else` 不是「否则」，而是「没被 break 时执行」。
