
## 🧩 函数

## 🚨 异常

```python
try:
    ...
except ValueError as e:
    print(e)
except (TypeError, KeyError):
    ...
except Exception as e:
    ...
else:
    ...          # 没异常时
finally:
    ...          # 一定执行

raise ValueError("错误信息")

class MyError(Exception):
    pass
```

| --- | --- |
| `SyntaxError` | 语法错误、中文标点、漏冒号 |
| `IndentationError` | 缩进不一致 |
| `NameError` | 变量没定义 |
| `TypeError` | 类型不匹配 |
| `ValueError` | 类型对、值不对 |
| `IndexError` | 下标越界 |
| `KeyError` | 字典键不存在 |
| `ZeroDivisionError` | 除以 0 |
| `FileNotFoundError` | 文件路径不对 |
| `ModuleNotFoundError` | 库没安装 |
| `RecursionError` | 递归太深/缺终止条件 |

## 🏛️ 面向对象

```python
class Student:
    school = "一中"                 # 类属性

    def __init__(self, name, score):
        self.name = name            # 实例属性
        self._score = score         # 约定私有

    def show(self):
        return f"{self.name}: {self._score}"

    @property
    def score(self):
        return self._score

    @score.setter
    def score(self, value):
        if 0 <= value <= 100:
            self._score = value

    @classmethod
    def create(cls, name):
        return cls(name, 0)

    @staticmethod
    def add(a, b):
        return a + b

class GoodStudent(Student):
    def __init__(self, name, score):
        super().__init__(name, score)
```

## 🧯 报错急救

| 报错 | 先检查 |
| --- | --- |
| `SyntaxError: invalid syntax` | 中文标点、漏冒号/括号、`=` 写成 `==` |
| `IndentationError` | 空格和 Tab 混用、缩进量不一致 |
| `NameError: name 'x' is not defined` | 变量名拼错、作用域、先赋值再使用 |
| `TypeError: can only concatenate str` | 字符串和数字相加，先 `str()` |
| `ValueError: invalid literal for int()` | `int("abc")`，输入不是数字 |
| `IndexError: list index out of range` | 下标越界，检查 `len()` |
| `KeyError` | 字典键不存在，用 `get()` |
| `AttributeError` | 对象没有该方法，检查类型和拼写 |
| `ModuleNotFoundError` | 没装库，`pip install` |
| `FileNotFoundError` | 路径不对/工作目录不同 |
| `UnicodeDecodeError` | 编码不对，试 `gbk` / `utf-8-sig` |
| `PermissionError` | 文件被占用/无权限 |
| `RecursionError` | 递归缺终止条件或太深 |
| 中文显示方框 | matplotlib/wordcloud 没设中文字体 |
