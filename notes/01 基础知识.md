## 1.1 Python 是什么

### 语言特征（人话版）

| 特征 | 通俗解释 |
| --- | --- |
| 解释型 | 不需要先编译成 exe，交给解释器逐行执行 |
| 动态类型 | 变量不用声明类型，赋什么值就是什么类型 |
| 强类型 | 但不会偷偷把 `"1" + 1` 变成 `2`，类型不对直接报错 |
| 面向对象 | 一切皆对象，连整数、函数都是对象 |
| 跨平台 | 同一份代码可在 Windows / macOS / Linux 跑 |
| 生态丰富 | 数据分析、AI、爬虫、游戏都有现成库 |

### 解释 vs 编译

```text
编译型（C）：源代码 ──编译──> 机器码 ──> 运行
解释型（Python）：源代码 ──> 字节码(.pyc) ──> Python 虚拟机逐条执行
```

- 解释型**开发快、跨平台**，但通常**运行慢**。
- Python 会先编译成字节码再解释执行，不是纯逐字翻译。
- 对多数应用来说，真正耗时的部分由 C 写的库（NumPy 等）完成，速度并不差。

### 安装与三种运行方式

1. **交互式（REPL）**：命令行输入 `python`，出现 `>>>` 后逐行输入，适合试验。
2. **脚本文件**：写 `hello.py`，命令行执行 `python hello.py`。
3. **IDE**：IDLE、PyCharm、VS Code，适合写完整项目。

```python
# hello.py
print("Hello, Python!")
```

```bash
python hello.py
```

### pip：Python 的「应用商店」

```bash
pip install requests          # 安装
pip install requests==2.31.0  # 指定版本
pip uninstall requests        # 卸载
pip list                      # 已安装列表
pip show requests             # 包详情
```

> [!TIP]
> **装不上怎么办**
> 先换国内镜像：`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple 包名`。仍失败就看报错最后一行，常见原因是网络、权限或 Python 版本不匹配。

## 1.2 程序的基本概念

### 保留字（关键字）

保留字是 Python 自己占用的单词，不能拿来当变量名。查看全部：

```python
import keyword
print(keyword.kwlist)
```

Python 3.10+ 共 35 个：

```text
False  None  True  and  as  assert  async  await  break  class
continue  def  del  elif  else  except  finally  for  from
global  if  import  in  is  lambda  nonlocal  not  or  pass
raise  return  try  while  with  yield
```

> [!NOTE]
> **不用背**
> 写多了自然记住。只需要知道：**这些词不能当名字**。

### 标识符（起名字的规则）

- 只能由**字母、数字、下划线**组成。
- **不能以数字开头**：`2name` ❌，`name2` ✅。
- **区分大小写**：`age` 和 `Age` 是两个变量。
- **不能用保留字**：`class` ❌。
- 中文也可以当变量名（Python 3 支持），但**不推荐**，兼容性和可读性都差。

常见命名习惯：

| 对象 | 风格 | 例子 |
| --- | --- | --- |
| 变量 / 函数 | 小写 + 下划线（snake_case） | `user_name`, `get_age()` |
| 常量 | 全大写 | `MAX_SIZE` |
| 类 | 大驼峰（PascalCase） | `StudentInfo` |
| 私有成员 | 前置下划线 | `_internal`, `__secret` |

### 算术运算

| 运算符 | 含义 | 例子 | 结果 |
| --- | --- | --- | --- |
| `+` | 加 | `3 + 2` | `5` |
| `-` | 减 | `3 - 2` | `1` |
| `*` | 乘 | `3 * 2` | `6` |
| `/` | 真除法 | `7 / 2` | `3.5` |
| `//` | 整除（向下取整） | `7 // 2` | `3` |
| `%` | 取余 | `7 % 2` | `1` |
| `**` | 幂 | `2 ** 10` | `1024` |

**三个容易翻车的细节：**

```python
print(7 / 2)     # 3.5   / 的结果永远是 float
print(-7 // 2)   # -4    向下取整，不是向零取整
print(-7 % 2)    # 1     余数的符号跟除数走
print(2 ** 3 ** 2)  # 512  幂运算右结合：2 ** (3 ** 2)
```

运算优先级（高 → 低）：

```text
**  →  正负号(+x, -x)  →  * / // %  →  + -  →  比较  →  not  →  and  →  or
```

拿不准就加括号，括号永远不嫌多。

### 其他运算

```python
# 比较运算：结果是 bool
print(3 > 2)          # True
print(1 < 5 < 10)     # True，可以连写

# 逻辑运算：短路求值
print(True and False) # False
print(False or True)  # True
print(not True)       # False

# 成员运算
print("a" in "cat")   # True
print(3 in [1, 2, 3]) # True

# 身份运算：是不是同一个对象
a = [1, 2]
b = [1, 2]
print(a == b)         # True  值相等
print(a is b)         # False 不是同一个对象
```

> [!WARNING]
> **`==` 和 `is` 别混**
> `==` 比较**值**，`is` 比较**内存地址（是不是同一个对象）**。判断 `None` 时习惯用 `x is None`，其余情况几乎都用 `==`。

逻辑运算的短路特性很实用：

```python
name = ""
print(name or "匿名用户")   # 匿名用户
```

`or` 返回第一个为真的操作数；如果都不为真，返回最后一个。所以它不一定返回 `True/False`。

### 转义字符

| 写法 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 制表符（Tab） |
| `\\` | 一个反斜杠 |
| `\'` / `\"` | 引号本身 |
| `\r` | 回车 |
| `\b` | 退格 |
| `\0` | 空字符 |

```python
print("第一行\n第二行")
print("姓名\t年龄")
print("C:\\Users\\test")     # 路径里的反斜杠要转义
print(r"C:\Users\test")      # 或者用原始字符串 r""
```

> [!TIP]
> **Windows 路径**
> 字符串里写路径，推荐用 `/`（Python 能识别）或原始字符串 `r"..."`，否则 `\t`、`\n` 会被当成转义。

## 1.3 程序结构与规范

### 一个 Python 程序由什么组成

```python
# 1. 注释：给人看的，不执行
import math          # 2. 导入语句

PI = 3.14159         # 3. 常量/变量赋值

def area(r):         # 4. 函数定义
    """计算圆面积。"""   # 文档字符串
    return PI * r ** 2

if __name__ == "__main__":   # 5. 主程序入口
    print(area(2))
```

### 缩进就是语法

Python 用缩进表示代码块，不用 `{}`：

```python
if 3 > 2:
    print("成立")     # 缩进 4 个空格，属于 if 内部
print("结束")         # 不缩进，属于 if 外部
```

规则：

- 同一代码块缩进必须**完全一致**。
- 推荐**每级 4 个空格**，不要用 Tab（或统一设置 Tab 转空格）。
- 冒号 `:` 后面跟代码块，至少要有一行，没有内容就写 `pass`。

```python
if 3 > 2:
    pass    # 占位，什么都不做
```

> [!WARNING]
> **最常见的报错**
> `IndentationError: expected an indented block` —— 该缩进没缩进。
> `IndentationError: unindent does not match any outer indentation level` —— 空格和 Tab 混用，或缩进量对不上。

### 注释

```python
# 单行注释

"""
多行字符串常被拿来当多行注释，
但它本质是字符串，不是真正的注释。
"""
```

### PEP 8 编程规范（重点几条就够）

| 规范 | 要求 |
| --- | --- |
| 缩进 | 4 个空格 |
| 行宽 | 每行不超过 79 个字符 |
| 空行 | 顶层函数/类之间空 2 行，类内方法之间空 1 行 |
| 命名 | 变量/函数 snake_case，类 PascalCase，常量 UPPER_CASE |
| 空格 | 运算符两边各一个空格，逗号后一个空格 |
| 导入 | 放文件顶部，按「标准库 → 第三方 → 本地」分组 |
| 比较 | 判断 `None` 用 `is None`，不用 `== None` |

```python
# 不推荐
x=1+2
y = [1,2,3]

# 推荐
x = 1 + 2
y = [1, 2, 3]
```

> [!TIP]
> **自动格式化**
> VS Code 里装 Black 或 Ruff 插件，保存时自动按规范排版，不用手调。

### 语法规则小结

- 语句结束**不需要分号**，一行一条语句。
- 一行写多条语句可以用 `;`，但不推荐。
- 长表达式可以用括号换行：

```python
total = (1 + 2 + 3 +
         4 + 5 + 6)
```

- 括号、引号必须成对，且用**英文半角**符号。中文引号 `“”`、中文括号 `（）` 是常见错误来源。

### 查帮助

```python
help(print)        # 查看函数说明
help("modules")    # 查看所有模块
dir(str)           # 查看字符串有哪些方法
print(str.upper.__doc__)   # 查看某个方法的文档
```

交互环境里 `help()` 会进入分页界面，按 `q` 退出。

### 程序路径

```python
import os
from pathlib import Path

print(os.getcwd())                    # 当前工作目录
print(os.path.abspath(__file__))      # 当前脚本的绝对路径
print(Path(__file__).parent)          # 当前脚本所在文件夹
```

> [!NOTE]
> **相对路径的坑**
> `open("data.txt")` 是相对于**运行程序时所在目录**，不是脚本所在目录。双击运行和命令行运行结果可能不同，必要时用 `Path(__file__).parent / "data.txt"` 拼绝对路径。

## ⚠️ 本章易错点

1. `/` 永远得到浮点数，要整数用 `//`。
2. `-7 // 2` 是 `-4`，不是 `-3`。
3. `input()` 得到的是字符串，算数前先转换。
4. 中文标点（，。：（）“”）会让程序报 `SyntaxError`。
5. 空格和 Tab 混用导致缩进错误。
6. 变量名用了保留字，如 `class = 1`。
7. `is` 用来判断同一个对象，别拿来比值。
8. 路径里的 `\t`、`\n` 被当成转义字符。

## 🧪 小练习

```python
# 1. 输入半径，输出圆面积和周长
r = float(input("半径："))
print(f"面积={3.14159 * r ** 2:.2f}，周长={2 * 3.14159 * r:.2f}")

# 2. 输入秒数，换算成时:分:秒
total = int(input("总秒数："))
h = total // 3600
m = total % 3600 // 60
s = total % 60
print(f"{h:02d}:{m:02d}:{s:02d}")
```
