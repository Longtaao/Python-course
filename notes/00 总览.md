## 💡 三句话抓住 Python

1. **变量是标签，不是盒子。** `a = [1, 2]` 是把 `a` 贴到列表对象上；`b = a` 只是多贴了一个标签，改 `b` 会同时改 `a`。
2. **缩进就是语法。** 同一代码块必须缩进一致（PEP 8 推荐 4 个空格），缩进错了程序含义就变了。
3. **库是 Python 的半条命。** 基础语法决定你能不能写，第三方库决定你能多快写完。

## 🛠️ 环境与常用库

### 安装 Python

1. 到 [python.org](https://www.python.org/downloads/) 下载 3.10 及以上版本。
2. Windows 安装时勾选 **Add Python to PATH**。
3. 验证：

```bash
python --version
pip --version
```

### 两种运行方式

```bash
python hello.py          # 运行脚本
python                   # 进入交互式环境，输入 exit() 退出
```

### 本书应用部分常用库

```bash
pip install openpyxl jieba matplotlib wordcloud networkx requests beautifulsoup4 pandas numpy scikit-learn pygame opencv-python pyttsx3 sympy scipy
```

国内网络慢时换清华镜像：

```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple 包名
```

### 常用命令速查

| 命令 | 作用 |
| --- | --- |
| `pip install 包名` | 安装 |
| `pip install 包名==版本号` | 安装指定版本 |
| `pip uninstall 包名` | 卸载 |
| `pip list` | 查看已安装 |
| `pip show 包名` | 查看包信息 |
| `python -m venv venv` | 创建虚拟环境 |

> [!TIP]
> **虚拟环境**
> 不同项目可能依赖不同版本。给每个项目建独立虚拟环境，能避免「装了这个，坏了那个」。本书案例多，建议一个应用章一个环境。

## 🧱 学习建议

- **每个例子都亲手敲一遍**，不要复制粘贴。报错信息是免费的老师。
- **先跑通，再改坏，再修好。** 把参数改一改、删一行、换个类型，观察结果。
- **每章至少产出一个能运行的小东西**：词频统计器、待办清单、成绩管理系统、小游戏。
- **先查官方文档，再搜教程**。Python 官方文档和库文档通常最准。
- 建立自己的**报错本**：把见过的 `Traceback` 和解决办法记下来，比背语法有用。

## 📌 全书高频易错点 Top 10

1. `input()` 返回字符串，做数学运算前要 `int()` / `float()`。
2. `/` 结果是浮点数，整除用 `//`。
3. 列表 `b = a` 是引用，不是复制；要复制用 `a.copy()` 或 `a[:]`。
4. 可变对象（列表、字典）不要做函数默认参数。
5. 字典的键必须不可变（不能是列表）。
6. `sort()` 原地排序返回 `None`，`sorted()` 返回新列表。
7. 文件操作记得指定 `encoding='utf-8'`，并用 `with` 自动关闭。
8. 中文图表要设置字体，否则显示方框。
9. 机器学习先划分训练/测试集，再在训练集上做标准化，防止数据泄露。
10. GUI 程序别忘了 `mainloop()`，游戏程序别忘了清屏和刷新。
