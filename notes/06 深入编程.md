## 6.1 异常处理

### 三类程序错误

| 类型 | 例子 | 何时发现 |
| --- | --- | --- |
| 语法错误 SyntaxError | `if x = 1:` | 运行前 |
| 运行时异常 | `1 / 0`、`int("abc")` | 运行中 |
| 逻辑错误 | 算法写错、条件写反 | 结果不对时 |

异常处理管的是第二类。

### 常见异常

| 异常 | 触发场景 |
| --- | --- |
| `ZeroDivisionError` | 除以 0 |
| `ValueError` | 类型对但值不对，如 `int("abc")` |
| `TypeError` | 类型不匹配，如 `"1" + 1` |
| `NameError` | 变量未定义 |
| `IndexError` | 列表下标越界 |
| `KeyError` | 字典键不存在 |
| `FileNotFoundError` | 文件不存在 |
| `AttributeError` | 对象没有该属性/方法 |
| `ImportError` | 模块导入失败 |

### 基本结构

```python
try:
    x = int(input("输入一个整数："))
    y = 10 / x
except ValueError:
    print("输入的不是整数")
except ZeroDivisionError:
    print("不能除以 0")
else:
    print("结果是", y)       # 没有异常时执行
finally:
    print("程序结束")         # 无论如何都执行
```

执行顺序：

```text
try 出错 → 找匹配的 except → 执行 finally
try 没出错 → 执行 else → 执行 finally
```

### 捕获多个异常

```python
try:
    ...
except (ValueError, TypeError) as e:
    print("出错了：", e)
```

`as e` 拿到异常对象，`str(e)` 是错误信息。

### 捕获所有异常

```python
try:
    ...
except Exception as e:
    print("未知错误：", e)
```

> [!WARNING]
> **别滥用裸 except**
> `except:` 会连 `Ctrl+C`、系统退出都吞掉，还会掩盖真正的 bug。至少写 `except Exception`，并且尽量指明具体类型。

### raise 主动抛异常

```python
def set_age(age):
    if age < 0:
        raise ValueError("年龄不能为负")
    return age
```

在 `except` 里可以用不带参数的 `raise` 把异常继续往上抛：

```python
try:
    ...
except ValueError:
    print("记录日志")
    raise          # 原样抛出，交给上层处理
```

### 自定义异常

```python
class BalanceError(Exception):
    """余额不足。"""
    pass

def withdraw(balance, amount):
    if amount > balance:
        raise BalanceError(f"余额不足：当前 {balance}，需要 {amount}")
    return balance - amount

try:
    withdraw(100, 200)
except BalanceError as e:
    print(e)
```

自定义异常通常继承 `Exception`，适合在项目里表达业务错误。

## 6.2 面向对象编程

### 为什么需要类

当数据和操作数据的方法越来越多，用一堆函数和字典会乱。类把「属性（数据）」和「方法（行为）」打包在一起。

### 类与对象

```python
class Student:
    school = "第一中学"          # 类属性，所有实例共享

    def __init__(self, name, score):
        self.name = name         # 实例属性
        self.score = score

    def introduce(self):
        return f"我是{self.name}，来自{self.school}，成绩{self.score}"

s1 = Student("小明", 90)
s2 = Student("小红", 95)

print(s1.introduce())
print(s2.school)                 # 第一中学
```

- `class` 定义类，类名用大驼峰。
- `__init__` 是构造方法，创建对象时自动调用。
- `self` 代表当前对象，必须是方法的第一个参数（调用时不用传）。
- `s1`、`s2` 是 `Student` 的**实例（对象）**。

### 类属性 vs 实例属性

```python
s1.school = "第二中学"      # 给 s1 单独加了一个实例属性
print(s1.school)            # 第二中学
print(s2.school)            # 第一中学，不受影响
print(Student.school)       # 第一中学
```

> [!NOTE]
> **查找顺序**
> 先找实例属性，再找类属性。给实例赋值只会创建/修改实例属性，不会改类属性。

### 公有与私有

Python 没有真正的 private，靠命名约定：

```python
class Account:
    def __init__(self, balance):
        self.balance = balance      # 公有
        self._pin = "1234"          # 约定私有：外部别直接访问
        self.__secret = "xyz"       # 名称改写：变成 _Account__secret

    def get_secret(self):
        return self.__secret
```

- `_name`：**约定**私有，靠自觉。
- `__name`：Python 会把名字改写成 `_类名__name`，外部不能直接用 `a.__secret`，但仍可通过改写后的名字访问，**不是安全机制**。

### 方法

```python
class Circle:
    PI = 3.14159

    def __init__(self, r):
        self.r = r

    def area(self):                 # 实例方法，第一个参数是 self
        return Circle.PI * self.r ** 2

    @staticmethod
    def add(a, b):                  # 静态方法：不访问实例/类
        return a + b

    @classmethod
    def from_diameter(cls, d):      # 类方法：第一个参数是类
        return cls(d / 2)
```

| 方法 | 第一个参数 | 用途 |
| --- | --- | --- |
| 实例方法 | `self` | 访问实例属性 |
| 类方法 `@classmethod` | `cls` | 操作类，常用作替代构造器 |
| 静态方法 `@staticmethod` | 无 | 逻辑相关但不需要 self/cls |

### 属性装饰器 @property

把方法伪装成属性，可以做取值校验：

```python
class Student:
    def __init__(self, score):
        self._score = score

    @property
    def score(self):
        return self._score

    @score.setter
    def score(self, value):
        if not 0 <= value <= 100:
            raise ValueError("成绩必须在 0-100 之间")
        self._score = value

s = Student(90)
print(s.score)      # 90，像属性一样访问
s.score = 85        # 走 setter
# s.score = 120     # ValueError
```

### 封装、继承、多态

**封装**：把数据和操作包在类里，只暴露必要接口。

**继承**：子类复用父类，再扩展。

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

class Dog(Animal):
    def speak(self):            # 重写父类方法
        return "汪汪"

class Cat(Animal):
    def speak(self):
        return "喵喵"

class Puppy(Dog):
    def __init__(self, name):
        super().__init__(name)   # 调用父类构造方法
        self.age = 1

    def speak(self):
        return super().speak() + "（奶声）"
```

**多态**：同一个方法名，不同对象有不同表现。

```python
for animal in [Dog("旺财"), Cat("咪咪")]:
    print(animal.name, animal.speak())
```

输出：

```text
旺财 汪汪
咪咪 喵喵
```

> [!TIP]
> **Python 的多态靠「鸭子类型」**
> 不要求有共同父类，只要对象有相同的方法就能替换使用：「走起来像鸭子、叫起来像鸭子，就是鸭子」。

### 常用魔术方法

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __str__(self):            # print(obj) 时显示
        return f"《{self.title}》"

    def __repr__(self):           # 调试/交互环境显示
        return f"Book({self.title!r}, {self.pages})"

    def __len__(self):            # len(obj)
        return self.pages

    def __eq__(self, other):      # obj1 == obj2
        return self.title == other.title

b = Book("Python", 300)
print(b)          # 《Python》
print(len(b))     # 300
```

## 6.3 函数式编程

核心思想：**把函数当普通值传来传去**，多用「对每个元素做什么」，少写循环。

### 匿名函数 lambda

```python
square = lambda x: x ** 2
print(square(5))          # 25

add = lambda a, b: a + b
print(add(2, 3))          # 5
```

lambda 只能写一个表达式，适合短小的临时函数。

### 高阶函数

接收函数作为参数，或返回函数的函数。

```python
nums = [1, 2, 3, 4, 5]

# map：对每个元素做变换
squares = list(map(lambda x: x ** 2, nums))

# filter：按条件筛选
evens = list(filter(lambda x: x % 2 == 0, nums))

# sorted：按 key 排序
students = [("Tom", 90), ("Amy", 95)]
students = sorted(students, key=lambda x: x[1], reverse=True)

# reduce：累积计算
from functools import reduce
product = reduce(lambda a, b: a * b, nums)   # 120
```

> [!NOTE]
> **map/filter 返回迭代器**
> Python 3 里 `map`、`filter` 返回惰性迭代器，要看到结果通常包一层 `list()`。

### 闭包

内层函数记住了外层函数的变量，即使外层已经返回。

```python
def make_counter():
    count = 0

    def counter():
        nonlocal count       # 修改外层变量
        count += 1
        return count

    return counter

c = make_counter()
print(c())   # 1
print(c())   # 2
```

### 装饰器（了解）

装饰器 = 在不改原函数代码的前提下，给函数加功能。

```python
def timer(func):
    def wrapper(*args, **kwargs):
        import time
        start = time.time()
        result = func(*args, **kwargs)
        print(f"耗时 {time.time() - start:.4f} 秒")
        return result
    return wrapper

@timer
def slow():
    import time
    time.sleep(1)

slow()
```

`@timer` 等价于 `slow = timer(slow)`。

### 生成器（了解）

用 `yield` 逐个产出值，不一次性占满内存：

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for x in countdown(3):
    print(x)      # 3 2 1
```

处理大文件、大数据流时很有用。

## 6.4 命名空间与作用域

### LEGB 规则

查找一个名字时，Python 按顺序找：

```text
L → Local（函数内部）
E → Enclosing（外层函数）
G → Global（模块全局）
B → Built-in（内置）
```

```python
x = "global"

def outer():
    x = "enclosing"

    def inner():
        x = "local"
        print(x)      # local

    inner()

outer()
```

### global 与 nonlocal

```python
count = 0

def inc():
    global count       # 修改全局
    count += 1

def outer():
    n = 0
    def inner():
        nonlocal n     # 修改外层函数的变量
        n += 1
        return n
    return inner
```

> [!WARNING]
> **赋值即局部**
> 函数里只要对某个名字赋值，Python 就把它当局部变量；如果之前读取它，会报 `UnboundLocalError`。这就是为什么需要 `global` / `nonlocal`。

## 6.5 内存管理与常见坑

### Python 怎么管理内存

- **引用计数**：每个对象记录有多少个引用，归零就回收。
- **垃圾回收（gc）**：处理循环引用（A 引用 B，B 引用 A）。
- 可以用 `sys.getrefcount(obj)` 看引用数，用 `id(obj)` 看对象地址。

```python
import sys
a = []
print(sys.getrefcount(a))   # 通常比实际多 1（getrefcount 的参数临时引用）
```

### 小整数缓存

Python 会缓存 -5 到 256 的整数，所以：

```python
a = 100
b = 100
print(a is b)     # True（同一对象）

x = 1000
y = 1000
print(x is y)     # 可能 False，别依赖
```

所以**永远用 `==` 比较值，`is` 只用于 `None`、`True`、`False` 这类单例**。

### 经典坑清单

**坑 1：可变默认参数**

```python
def f(lst=[]):       # ❌ 所有调用共享同一个列表
    lst.append(1)
    return lst
```

改为 `lst=None`。

**坑 2：浅拷贝**

```python
import copy
a = [[1], [2]]
b = a.copy()          # 内层列表仍共享
c = copy.deepcopy(a)  # 完全独立
```

**坑 3：闭包延迟绑定**

```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])   # [2, 2, 2]，不是 [0, 1, 2]
```

因为 lambda 执行时才去找 `i`，那时循环已结束。用默认参数固定：

```python
funcs = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])   # [0, 1, 2]
```

**坑 4：遍历时修改列表**

```python
nums = [1, 2, 3, 4]
for x in nums:
    if x % 2 == 0:
        nums.remove(x)     # 会漏掉元素
```

遍历副本 `nums[:]`，或倒序删除，或生成新列表。

**坑 5：`==` 与 `is` 混用**

```python
a = [1, 2]
b = [1, 2]
print(a == b)    # True
print(a is b)    # False
```

**坑 6：整数除法**

```python
print(5 / 2)     # 2.5
print(5 // 2)    # 2
```

**坑 7：变量作用域**

```python
x = 1
def f():
    print(x)
    x = 2        # ❌ UnboundLocalError
```

因为函数里出现了对 `x` 的赋值，`x` 被视为局部变量。

### 优雅编程小案例

```python
# 不优雅
result = []
for i in range(10):
    if i % 2 == 0:
        result.append(i * i)

# 优雅
result = [i * i for i in range(10) if i % 2 == 0]

# 同时拿下标和值
for i, name in enumerate(names):
    print(i, name)

# 同时遍历两个列表
for name, score in zip(names, scores):
    print(name, score)

# 交换变量
a, b = b, a
```

## 6.6 打包成可执行文件

用 PyInstaller 把 `.py` 变成 `.exe`：

```bash
pip install pyinstaller
pyinstaller -F -w main.py
```

| 参数 | 作用 |
| --- | --- |
| `-F` / `--onefile` | 打包成单个 exe |
| `-w` / `--noconsole` | 不显示黑色命令行窗口（GUI 程序用） |
| `-i icon.ico` | 设置图标 |

生成的文件在 `dist/` 目录。注意：

- 打包体积大是正常的（带了解释器）。
- 某些杀毒软件会误报，需加白名单。
- 依赖数据文件（图片、字体）时要额外用 `--add-data`。

## ⚠️ 本章易错点

1. `except` 写得太宽，掩盖真正的 bug。
2. `finally` 里写 `return`，会吞掉异常。
3. 子类重写 `__init__` 忘记 `super().__init__()`。
4. 把 `self` 漏写，或调用方法时多传了 `self`。
5. 认为 `__` 私有是安全的（只是改名，不是加密）。
6. 用可变对象当默认参数。
7. 用 `is` 比较数值或字符串。
8. 闭包里循环变量延迟绑定。
9. 遍历列表时增删元素。
10. 忘记 `nonlocal` / `global`，导致 `UnboundLocalError`。
