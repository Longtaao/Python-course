## 9.1 matplotlib

```bash
pip install matplotlib
```

### 中文显示（第一件事）

```python
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["SimHei"]   # 黑体
plt.rcParams["axes.unicode_minus"] = False     # 正常显示负号
```

> [!WARNING]
> **中文变方框**
> 不是字体问题，是 matplotlib 默认字体不含中文。Windows 可用 `SimHei` 或 `Microsoft YaHei`，macOS 可用 `Arial Unicode MS`，Linux 需安装中文字体。

### 基本流程

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]

plt.plot(x, y)
plt.title("简单折线图")
plt.xlabel("X 轴")
plt.ylabel("Y 轴")
plt.show()
```

更多设置：

```python
plt.plot(x, y,
         color="red",
         linestyle="--",
         marker="o",
         linewidth=2,
         label="销售额")

plt.title("2026 年销售额", fontsize=14)
plt.xlabel("月份")
plt.ylabel("万元")
plt.xlim(0, 6)
plt.ylim(0, 12)
plt.xticks(x, ["一月", "二月", "三月", "四月", "五月"])
plt.legend()          # 显示图例
plt.grid(alpha=0.3)
plt.savefig("chart.png", dpi=300, bbox_inches="tight")
plt.show()
```

> [!TIP]
> **savefig 放在 show 前面**
> `show()` 在某些后端会清空画布，之后再保存可能得到空白图。先保存，再显示。

### 常用图形

**散点图：看两个变量的关系**

```python
x = [1, 2, 3, 4, 5]
y = [2, 3, 5, 4, 6]
plt.scatter(x, y, s=80, c="orange", alpha=0.7)
plt.show()
```

**柱状图：比较类别大小**

```python
subjects = ["语文", "数学", "英语"]
scores = [85, 95, 90]
plt.bar(subjects, scores, color=["#4e79a7", "#f28e2b", "#59a14f"])
plt.title("各科成绩")
plt.show()
```

**直方图：看数据分布**

```python
import random
ages = [random.randint(10, 60) for _ in range(500)]

plt.hist(ages, bins=10, edgecolor="black")
plt.xlabel("年龄")
plt.ylabel("人数")
plt.show()
```

`bins` 是分组的数量，太小看不出分布，太大显得毛躁。

**饼图：看占比**

```python
labels = ["苹果", "香蕉", "橙子", "葡萄"]
sizes = [35, 25, 20, 20]

plt.pie(sizes, labels=labels, autopct="%1.1f%%", startangle=90)
plt.axis("equal")      # 保证是正圆
plt.title("水果销量占比")
plt.show()
```

### 子图

```python
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

axes[0, 0].plot([1, 2, 3], [1, 4, 9])
axes[0, 0].set_title("折线")

axes[0, 1].bar(["A", "B"], [3, 7])
axes[0, 1].set_title("柱状")

axes[1, 0].hist([1, 2, 2, 3, 3, 3, 4])
axes[1, 0].set_title("直方")

axes[1, 1].pie([4, 6], labels=["A", "B"])
axes[1, 1].set_title("饼图")

plt.tight_layout()     # 自动调整间距
plt.show()
```

### 动态图（了解）

```python
import matplotlib.pyplot as plt
import matplotlib.animation as animation
import random

fig, ax = plt.subplots()
x = list(range(30))
y = [random.randint(0, 100) for _ in range(30)]
line, = ax.plot(x, y)

def update(frame):
    y.pop(0)
    y.append(random.randint(0, 100))
    line.set_ydata(y)
    return line,

ani = animation.FuncAnimation(fig, update, interval=200, blit=True)
plt.show()
```

冒泡排序动态图同理：每一帧更新柱子的高度。

## 9.2 词云图 wordcloud

```bash
pip install wordcloud
```

### 普通词云

```python
from wordcloud import WordCloud

text = "Python 数据分析 可视化 机器学习 人工智能 Python 数据"

wc = WordCloud(
    font_path="C:/Windows/Fonts/msyh.ttc",   # 中文字体，必须指定
    width=800,
    height=600,
    background_color="white",
    max_words=100,
)
wc.generate(text)
wc.to_file("wordcloud.png")
```

> [!WARNING]
> **三个常见问题**
> 1. 包名是 `wordcloud`，不是 `WordCloud`。
> 2. 中文必须指定 `font_path`，否则全是方框。
> 3. `generate()` 接收的是**空格分隔的字符串**，中文先用 jieba 分词并用空格连接。

```python
import jieba
words = jieba.lcut(text)
text = " ".join(words)
```

### 自定义停用词与配色

```python
from wordcloud import WordCloud, STOPWORDS

wc = WordCloud(
    font_path="C:/Windows/Fonts/msyh.ttc",
    background_color="black",
    colormap="viridis",
    stopwords=STOPWORDS | {"的", "了", "是"},
    max_font_size=100,
    random_state=42,
)
```

### 遮罩词云

用一张图片的形状限制词云轮廓：

```python
import numpy as np
from PIL import Image
from wordcloud import WordCloud

mask = np.array(Image.open("heart.png"))

wc = WordCloud(
    font_path="C:/Windows/Fonts/msyh.ttc",
    mask=mask,
    background_color="white",
    contour_width=2,
    contour_color="red",
)
wc.generate(text)
wc.to_file("heart_cloud.png")
```

- 遮罩图白色区域会被忽略，非白色区域作为词云形状。
- 图片尺寸越大，生成的词云越清晰。

## 9.3 网络图 networkx

```bash
pip install networkx
```

### 创建图

```python
import networkx as nx

G = nx.Graph()                 # 无向图
# G = nx.DiGraph()             # 有向图

G.add_node("刘备")
G.add_nodes_from(["关羽", "张飞", "曹操"])
G.add_edge("刘备", "关羽")
G.add_edges_from([("刘备", "张飞"), ("曹操", "刘备")])
```

### 查看信息

```python
print(G.number_of_nodes(), G.number_of_edges())
print(list(G.nodes()))
print(list(G.edges()))
print(G.degree("刘备"))          # 连接数
```

### 绘制

```python
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["SimHei"]
plt.rcParams["axes.unicode_minus"] = False

pos = nx.spring_layout(G, seed=42)   # 力导向布局

nx.draw_networkx_nodes(G, pos, node_size=800, node_color="lightblue")
nx.draw_networkx_edges(G, pos, width=1.5)
nx.draw_networkx_labels(G, pos, font_family="SimHei", font_size=12)

plt.axis("off")
plt.show()
```

> [!NOTE]
> **布局影响观感**
> `spring_layout` 像弹簧一样把有联系的节点拉近；还可以用 `circular_layout`（环形）、`random_layout`（随机）、`kamada_kawai_layout`（更均匀）。

### 边的权重

```python
G.add_edge("刘备", "关羽", weight=5)
G.add_edge("刘备", "张飞", weight=3)

widths = [G[u][v]["weight"] * 0.5 for u, v in G.edges()]
nx.draw_networkx_edges(G, pos, width=widths)
```

### 中心性分析

```python
degree = nx.degree_centrality(G)      # 度中心性：连接越多越重要
pagerank = nx.pagerank(G)             # PageRank：被重要节点连接也重要

top = sorted(degree.items(), key=lambda x: x[1], reverse=True)
print(top[:5])
```

### 读写网络数据

```python
# 边列表：每行两个节点
G = nx.read_edgelist("edges.txt", delimiter=",")
nx.write_edgelist(G, "out.txt", delimiter=",")

# 带权重的边列表
G = nx.read_weighted_edgelist("weighted.txt", delimiter=",")
```

### 案例：《三国演义》人物关系图

思路：

1. 读取文本，按章节/段落切分。
2. 每一段中找出同时出现的人物名。
3. 同段共现的两个人之间加一条边，权重 +1。
4. 用 `spring_layout` 绘制，节点大小按度中心性设置。

```python
import networkx as nx
import matplotlib.pyplot as plt

names = ["刘备", "关羽", "张飞", "曹操", "孙权", "诸葛亮", "赵云"]
G = nx.Graph()

# 简化：假设从文本中统计出共现次数
co_occur = {
    ("刘备", "关羽"): 55, ("刘备", "张飞"): 48,
    ("刘备", "诸葛亮"): 40, ("曹操", "刘备"): 30,
    ("孙权", "刘备"): 20, ("赵云", "刘备"): 25,
}
for (a, b), w in co_occur.items():
    G.add_edge(a, b, weight=w)

pos = nx.spring_layout(G, seed=42)
sizes = [G.degree(n) * 200 for n in G.nodes()]

nx.draw_networkx_nodes(G, pos, node_size=sizes, node_color="skyblue")
nx.draw_networkx_edges(G, pos, width=[G[u][v]["weight"] / 20 for u, v in G.edges()])
nx.draw_networkx_labels(G, pos, font_family="SimHei")

plt.axis("off")
plt.show()
```

真实项目里，共现统计需要先做**人名识别**（可以用 jieba 词性标注 `nr` 或预先准备人物表）。

## ⚠️ 本章易错点

1. 中文显示方框，忘记设置 `font.sans-serif`。
2. 负号显示成方块，忘记 `axes.unicode_minus = False`。
3. `plt.show()` 之后再 `savefig`，保存出空白图。
4. 多次 `plot` 不 `show`，图叠在一起；需要 `plt.figure()` 开新图。
5. `wordcloud` 包名写错，或中文没指定字体。
6. 词云输入是列表而不是字符串；应 `" ".join(words)`。
7. networkx 节点中文标签乱码，`draw_networkx_labels` 要单独设字体。
8. 图太小/节点重叠，调整 `figsize`、`node_size`、`k` 参数。
9. matplotlib 默认不支持交互旋转，需要额外后端。
10. `plt.pie` 不加 `axis("equal")`，饼图可能变成椭圆。
