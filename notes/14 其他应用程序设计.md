## 14.1 图像处理程序设计

```bash
pip install opencv-python
```

导入名是 `cv2`。

### 读取、显示、保存

```python
import cv2

img = cv2.imread("photo.jpg")       # 默认读成 BGR
print(img.shape)                    # (高, 宽, 通道)

cv2.imshow("原图", img)
cv2.waitKey(0)                      # 等待按键，0 表示一直等
cv2.destroyAllWindows()

cv2.imwrite("out.jpg", img)
```

> [!WARNING]
> **OpenCV 的三个坑**
> 1. **颜色顺序是 BGR**，不是 RGB。用 matplotlib 显示前要 `cv2.cvtColor(img, cv2.COLOR_BGR2RGB)`。
> 2. `imshow()` 后必须 `waitKey()`，否则窗口不刷新。
> 3. Windows 下中文路径 `imread` 可能读不到，用下面的写法：
> ```python
> import numpy as np
> img = cv2.imdecode(np.fromfile("图片.jpg", dtype=np.uint8), cv2.IMREAD_COLOR)
> ```

### 常用操作

```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)      # 转灰度
resized = cv2.resize(img, (300, 200))              # 缩放
blur = cv2.GaussianBlur(img, (5, 5), 0)            # 高斯模糊
edges = cv2.Canny(gray, 100, 200)                  # 边缘检测

# 二值化：大于 127 变白，否则变黑
_, thresh = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

# Otsu 自动阈值（更常用）
_, thresh = cv2.threshold(gray, 0, 255,
                          cv2.THRESH_BINARY + cv2.THRESH_OTSU)
```


### 案例：B 超图像面积计算

思路：灰度 → 去噪 → 二值化 → 找轮廓 → 算面积 → 按比例换算成真实面积。

```python
import cv2
import numpy as np

img = cv2.imread("b_ultrasound.jpg")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(gray, (5, 5), 0)

_, thresh = cv2.threshold(blur, 0, 255,
                          cv2.THRESH_BINARY + cv2.THRESH_OTSU)

# 形态学去噪：先腐蚀再膨胀
kernel = np.ones((5, 5), np.uint8)
thresh = cv2.morphologyEx(thresh, cv2.MORPH_OPEN, kernel)

contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL,
                               cv2.CHAIN_APPROX_SIMPLE)

if contours:
    largest = max(contours, key=cv2.contourArea)
    pixel_area = cv2.contourArea(largest)

    # 假设图像中标尺：1 像素 = 0.5 毫米
    mm_per_pixel = 0.5
    real_area = pixel_area * mm_per_pixel ** 2

    print(f"像素面积：{pixel_area:.0f}")
    print(f"实际面积：{real_area:.2f} mm²")

    cv2.drawContours(img, [largest], -1, (0, 255, 0), 2)
    cv2.imshow("result", img)
    cv2.waitKey(0)
    cv2.destroyAllWindows()
```

关键：**像素面积没有物理意义，必须知道比例尺**（比如图像里的标尺或设备参数）。

### 案例：图像中的物体计数

```python
import cv2
import numpy as np

img = cv2.imread("objects.jpg")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(gray, (7, 7), 0)

_, thresh = cv2.threshold(blur, 0, 255,
                          cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)

contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL,
                               cv2.CHAIN_APPROX_SIMPLE)

count = 0
for c in contours:
    area = cv2.contourArea(c)
    if area < 100:            # 过滤噪点
        continue
    count += 1
    x, y, w, h = cv2.boundingRect(c)
    cv2.rectangle(img, (x, y), (x + w, y + h), (0, 255, 0), 2)

print("物体数量：", count)
```

- `THRESH_BINARY_INV`：深色物体变白，便于找轮廓。
- 面积过滤能去掉小噪点。
- 物体粘连时需要用分水岭算法或距离变换。

## 14.2 语音合成程序设计

### 14.2.1 TTS 原理

TTS（Text To Speech）= 文本 → 分词/韵律分析 → 声学模型 → 音频波形。实际开发直接调用现成引擎。

### 14.2.2 pyttsx3：跨平台朗读

```bash
pip install pyttsx3
```

```python
import pyttsx3

engine = pyttsx3.init()

# 语速（默认约 200）
engine.setProperty("rate", 150)

# 音量 0.0–1.0
engine.setProperty("volume", 0.9)

# 选择声音
voices = engine.getProperty("voices")
engine.setProperty("voice", voices[0].id)
# voices[1].id 可能是女声，取决于系统

engine.say("你好，欢迎学习 Python")
engine.runAndWait()          # 必须调用，否则不发声
```

保存为音频文件：

```python
engine.save_to_file("这是要保存的语音", "output.mp3")
engine.runAndWait()
```

> [!WARNING]
> **两个常见问题**
> 1. 只 `say()` 不 `runAndWait()`，程序直接结束，没有声音。
> 2. Linux 缺少 `espeak` 或音频驱动会报错；Windows 通常开箱即用。

### 案例：语音天气预报

思路：用 requests 调天气 API 拿数据 → 拼成一句话 → pyttsx3 朗读。

```python
import requests
import pyttsx3

def get_weather(city):
    # 示例接口，实际使用需替换为可用的 API 和 key
    url = f"https://api.example.com/weather?city={city}"
    resp = requests.get(url, timeout=10)
    data = resp.json()
    return data["weather"], data["temperature"]

def speak(text):
    engine = pyttsx3.init()
    engine.setProperty("rate", 160)
    engine.say(text)
    engine.runAndWait()

weather, temp = get_weather("北京")
speak(f"北京今天{weather}，气温{temp}摄氏度")
```

## 14.3 科学计算程序设计

### 14.3.1 SymPy：符号计算

```bash
pip install sympy
```

符号计算得到的是**表达式**，不是近似数值。

```python
from sympy import symbols, expand, factor, simplify, solve, diff, integrate, limit, oo, sin, exp

x, y = symbols("x y")

print(expand((x + y) ** 2))       # x**2 + 2*x*y + y**2
print(factor(x**2 - 1))           # (x - 1)*(x + 1)
print(simplify((x**2 - 1) / (x - 1)))   # x + 1

print(solve(x**2 - 4, x))         # [-2, 2]
print(solve([x + y - 3, x - y - 1], [x, y]))   # {x: 2, y: 1}

print(diff(x**3, x))              # 3*x**2
print(integrate(x**2, x))         # x**3/3
print(integrate(x**2, (x, 0, 1))) # 1/3

print(limit(sin(x) / x, x, 0))    # 1
print(limit(1 / x, x, oo))        # 0
```

> [!NOTE]
> **符号 vs 数值**
> `sympy` 算精确表达式，适合推导公式；`numpy/scipy` 算浮点近似，适合工程计算。需要小数结果时用 `expr.evalf()`。

### 14.3.2 曲线拟合

用已知函数形式去拟合实验数据。

```python
import numpy as np
from scipy.optimize import curve_fit
import matplotlib.pyplot as plt

# 模型：y = a * exp(b * x)
def model(x, a, b):
    return a * np.exp(b * x)

xdata = np.array([0, 1, 2, 3, 4, 5])
ydata = np.array([2.1, 2.8, 3.9, 5.1, 7.2, 9.8])

popt, pcov = curve_fit(model, xdata, ydata, p0=[1, 0.3])
print("拟合参数：", popt)

plt.scatter(xdata, ydata, label="实验数据")
plt.plot(xdata, model(xdata, *popt), "r-", label="拟合曲线")
plt.legend()
plt.show()
```

- `p0` 是初始猜测，模型复杂时很重要。
- `pcov` 是协方差矩阵，对角线开方是参数误差。

### 14.3.3 积分运算

```python
from scipy.integrate import quad

result, error = quad(lambda x: x**2, 0, 1)
print(result, error)      # 0.33333333333333337 3.7e-15
```

### 14.3.4 解线性方程组

```python
import numpy as np

# 2x + y = 5
# x + 3y = 10
A = np.array([[2, 1],
              [1, 3]])
b = np.array([5, 10])

solution = np.linalg.solve(A, b)
print(solution)      # [1. 3.]
```

也可以用 SymPy 求精确解：

```python
from sympy import Matrix

A = Matrix([[2, 1], [1, 3]])
b = Matrix([5, 10])
print(A.LUsolve(b))       # Matrix([[1], [3]])
print(A.det(), A.inv())
```

### 14.3.5 解微分方程组

```python
import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

# dy/dt = -0.5y
def model(y, t):
    return -0.5 * y

t = np.linspace(0, 10, 100)
y0 = 5

solution = odeint(model, y0, t)

plt.plot(t, solution)
plt.xlabel("t")
plt.ylabel("y")
plt.show()
```

> [!WARNING]
> **参数顺序**
> `odeint(func, y0, t)` 中 `func(y, t)` 是**先 y 后 t**；而 `solve_ivp(func, t_span, y0)` 中 `func(t, y)` 是**先 t 后 y**，别搞混。

方程组就是让 `model` 返回列表：

```python
def model(state, t):
    x, y = state
    dx = -0.1 * x + 0.02 * x * y
    dy = 0.2 * y - 0.01 * x * y
    return [dx, dy]
```

### 14.3.6 逻辑运算

SymPy 可以化简和验证逻辑表达式：

```python
from sympy import symbols
from sympy.logic.boolalg import And, Or, Not, Implies, Equivalent, simplify_logic

p, q = symbols("p q")

expr = Implies(p, q)
print(simplify_logic(expr))          # ~p | q

# 真值表
from sympy.logic.boolalg import truth_table
for assignment, value in truth_table(expr, [p, q]):
    print(assignment, value)
```

Python 自带的逻辑运算 `and/or/not`、位运算 `& | ~` 也能做简单逻辑判断，但不做公式化简。

## ⚠️ 本章易错点

1. OpenCV 读进来是 BGR，matplotlib 显示颜色不对。
2. `imshow()` 后不 `waitKey()`，窗口不响应。
3. Windows 中文路径 `imread` 返回 `None`，用 `imdecode`。
4. 二值化前不去噪，轮廓碎成一堆。
5. 像素面积直接当实际面积，忘记比例尺。
6. `findContours` 的返回值在不同 OpenCV 版本中形式不同（3 个 vs 2 个）。
7. pyttsx3 只 `say()` 不 `runAndWait()`，没有声音。
8. SymPy 的 `symbols` 忘记声明，变量被当成普通 Python 变量。
9. 符号结果想要小数，忘记 `.evalf()`。
10. `odeint` 和 `solve_ivp` 的参数顺序不同，函数写反。
