## 5.1 打开文件

### 基本语法

```python
f = open("data.txt", "r", encoding="utf-8")
content = f.read()
f.close()          # 一定要关
```

更推荐：

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
# 离开 with 块自动关闭，即使中途出错也会关
```

> [!TIP]
> **为什么用 with**
> 手动 `close()` 时，如果中间抛异常，文件可能一直不关。`with` 是上下文管理器，能保证关闭。

### 模式

| 模式 | 含义 | 文件不存在 | 文件已存在 |
| --- | --- | --- | --- |
| `"r"` | 只读（默认） | 报错 | 从头读 |
| `"w"` | 只写 | 创建 | **清空重写** |
| `"a"` | 追加 | 创建 | 末尾追加 |
| `"x"` | 独占创建 | 创建 | 报错 |
| `"r+"` | 读写 | 报错 | 从头读写 |
| `"b"` | 二进制模式 | — | 与上面组合：`"rb"`、`"wb"` |
| `"t"` | 文本模式（默认） | — | — |

> [!WARNING]
> **`"w"` 很危险**
> 打开就清空，哪怕你还没写任何东西。不确定时先用 `"a"` 或先备份。

### 编码

```python
# 读
with open("data.txt", encoding="utf-8") as f:
    text = f.read()

# 写
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("你好")
```

Windows 上不指定 `encoding` 时，Python 可能用系统默认编码（GBK），和 UTF-8 文件混用就会乱码。**养成每次都写 `encoding="utf-8"` 的习惯。**

## 5.2 读取文件

假设 `poem.txt` 内容：

```text
床前明月光
疑是地上霜
举头望明月
低头思故乡
```

### 读全部

```python
with open("poem.txt", encoding="utf-8") as f:
    text = f.read()        # 整个文件一个字符串
print(text)
```

### 读指定字符数

```python
with open("poem.txt", encoding="utf-8") as f:
    part = f.read(5)       # 读 5 个字符
    rest = f.read()        # 读剩下的
```

### 读一行

```python
with open("poem.txt", encoding="utf-8") as f:
    line1 = f.readline()   # 包含结尾的 \n
    line2 = f.readline()
```

### 读所有行成列表

```python
with open("poem.txt", encoding="utf-8") as f:
    lines = f.readlines()  # ['床前明月光\n', '疑是地上霜\n', ...]

# 去掉每行结尾的换行符
lines = [line.strip() for line in lines]
```

### 逐行遍历（推荐，省内存）

```python
with open("poem.txt", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

大文件不要 `read()` 一次性读入，逐行处理内存占用小得多。

### 常用读取方式对比

| 方法 | 返回 | 适用 |
| --- | --- | --- |
| `read()` | 一个字符串 | 小文件 |
| `read(n)` | n 个字符/字节 | 分块处理 |
| `readline()` | 一行字符串 | 逐行读 |
| `readlines()` | 字符串列表 | 小文件、需要列表 |
| `for line in f` | 逐行迭代 | 大文件首选 |

## 5.3 写入文件

```python
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")
```

- `write()` 不会自动加换行，需要自己写 `\n`。
- `writelines()` 也不会加换行：

```python
lines = ["第一行\n", "第二行\n"]
with open("out.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)
```

追加：

```python
with open("out.txt", "a", encoding="utf-8") as f:
    f.write("追加的一行\n")
```

写入数字要先转字符串：

```python
f.write(str(123))
```

## 5.4 常用文件操作

### 5.4.1 格式化写入

```python
students = [("小明", 90), ("小红", 95)]

with open("scores.txt", "w", encoding="utf-8") as f:
    for name, score in students:
        f.write(f"{name},{score}\n")
```

生成的文件：

```text
小明,90
小红,95
```

### 5.4.2 多个文件合并

把多个文件的**内容按顺序**接到一个文件里：

```python
files = ["a.txt", "b.txt", "c.txt"]

with open("merged.txt", "w", encoding="utf-8") as out:
    for name in files:
        with open(name, encoding="utf-8") as f:
            out.write(f.read())
            out.write("\n")
```

### 5.4.3 多个文件连接

按行「拼接」两个文件（如姓名表和成绩表）：

```python
with open("names.txt", encoding="utf-8") as f1, \
     open("scores.txt", encoding="utf-8") as f2, \
     open("result.txt", "w", encoding="utf-8") as out:
    for name, score in zip(f1, f2):
        out.write(f"{name.strip()} {score.strip()}\n")
```

### 5.4.4 文件内容去重

```python
seen = set()
with open("input.txt", encoding="utf-8") as f, \
     open("unique.txt", "w", encoding="utf-8") as out:
    for line in f:
        line = line.strip()
        if line and line not in seen:
            seen.add(line)
            out.write(line + "\n")
```

用 `set` 判断是否见过，时间复杂度接近 O(1)。

### 5.4.5 案例：字符统计

统计文件里每个字符出现的次数：

```python
from collections import Counter

with open("poem.txt", encoding="utf-8") as f:
    text = f.read()

# 去掉空白和换行
text = "".join(text.split())

count = Counter(text)
for char, n in count.most_common(10):
    print(char, n)
```

统计英文单词：

```python
import re
from collections import Counter

with open("article.txt", encoding="utf-8") as f:
    text = f.read().lower()

words = re.findall(r"[a-z]+", text)
print(Counter(words).most_common(10))
```

## 5.5 文本编码

### 为什么会有乱码

计算机只存字节。**编码**是「字符 → 字节」的规则，**解码**是反过来。用 A 规则编码、却用 B 规则解码，就会乱码。

| 编码 | 特点 |
| --- | --- |
| ASCII | 1 字节，只支持英文和基本符号 |
| GBK | 中文编码，Windows 中文环境常见，1–2 字节 |
| UTF-8 | 国际通用，英文 1 字节、中文通常 3 字节，**推荐** |
| Unicode | 字符集标准，给每个字符编号；UTF-8 是它的常用实现 |

### encode 与 decode

```python
s = "你好"

b = s.encode("utf-8")       # 字符串 → 字节
print(b)                    # b'\xe4\xbd\xa0\xe5\xa5\xbd'
print(type(b))              # <class 'bytes'>

print(b.decode("utf-8"))    # 字节 → 字符串：你好
```

用错编码：

```python
b = "你好".encode("gbk")
print(b.decode("utf-8"))    # UnicodeDecodeError 或乱码
```

### 文件编码转换

把 GBK 文件转成 UTF-8：

```python
with open("gbk.txt", encoding="gbk") as f:
    text = f.read()

with open("utf8.txt", "w", encoding="utf-8") as f:
    f.write(text)
```

### 自动检测编码

```python
# pip install chardet
import chardet

with open("unknown.txt", "rb") as f:
    raw = f.read()

result = chardet.detect(raw)
print(result)      # {'encoding': 'gbk', 'confidence': 0.99, ...}

text = raw.decode(result["encoding"])
```

### 处理解码错误

```python
raw.decode("utf-8", errors="ignore")   # 跳过无法解码的字节
raw.decode("utf-8", errors="replace")  # 用 � 替换
```

### BOM 问题

有些 Windows 文件开头带 BOM（`\ufeff`），读出来第一个字符会多一个隐形符号：

```python
with open("bom.csv", encoding="utf-8-sig") as f:   # 自动去掉 BOM
    ...
```

## 5.6 路径处理

### 相对路径 vs 绝对路径

```text
相对路径：data.txt、../data/a.txt      相对于「当前工作目录」
绝对路径：D:\work\data.txt            从盘符/根目录开始
```

查看当前工作目录：

```python
import os
print(os.getcwd())
```

### 拼接路径

```python
import os

path = os.path.join("data", "2026", "scores.txt")
print(path)          # data\2026\scores.txt（Windows 自动用反斜杠）

print(os.path.exists(path))
print(os.path.dirname(path))
print(os.path.basename(path))
```

### pathlib（更现代的写法）

```python
from pathlib import Path

p = Path("data") / "2026" / "scores.txt"
print(p.exists())
print(p.parent)
print(p.name)
print(p.suffix)

# 相对于脚本所在目录
base = Path(__file__).parent
file = base / "data.txt"
```

> [!WARNING]
> **双击运行 vs 命令行运行**
> `open("data.txt")` 找的是「当前工作目录」，不是脚本目录。两者可能不同。稳妥做法是用 `Path(__file__).parent` 拼出脚本旁边的文件。

## ⚠️ 本章易错点

1. 不指定 `encoding`，Windows 下默认 GBK，读 UTF-8 文件乱码。
2. 用 `"w"` 打开已存在的文件，内容立即被清空。
3. `write()` 不会自动换行，忘了写 `\n`。
4. `readlines()` 每行末尾带 `\n`，统计前要 `strip()`。
5. 忘记关闭文件；应使用 `with`。
6. Windows 路径写 `"C:\new\test.txt"`，`\n`、`\t` 被转义；用 `r"..."` 或 `/`。
7. 读取大文件用 `read()` 一次性载入，内存爆掉。
8. 文件不存在直接 `open("r")` 会报 `FileNotFoundError`；先判断或捕获异常。
9. 用 GBK 解码 UTF-8 字节，出现 `UnicodeDecodeError`。
10. `utf-8` 文件带 BOM，读出的第一个字符是 `\ufeff`；用 `utf-8-sig`。

## 🧪 小练习

```python
# 1. 统计文件行数、单词数、字符数
with open("article.txt", encoding="utf-8") as f:
    text = f.read()

print("行数：", len(text.splitlines()))
print("单词数：", len(text.split()))
print("字符数：", len(text))

# 2. 把文件中所有 "Python" 替换成 "PYTHON"
with open("in.txt", encoding="utf-8") as f:
    content = f.read()

with open("out.txt", "w", encoding="utf-8") as f:
    f.write(content.replace("Python", "PYTHON"))
```
