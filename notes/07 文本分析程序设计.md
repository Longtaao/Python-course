## 7.1 CSV 文件读写

CSV（Comma-Separated Values）就是「用逗号分隔的纯文本表格」。

```text
姓名,语文,数学,英语
小明,90,95,88
小红,85,92,96
```

### 读取 CSV

```python
import csv

with open("scores.csv", encoding="utf-8-sig", newline="") as f:
    reader = csv.reader(f)
    header = next(reader)          # 第一行是表头
    for row in reader:
        print(row)                 # row 是字符串列表
```

输出：

```text
['小明', '90', '95', '88']
['小红', '85', '92', '96']
```

> [!WARNING]
> **两个参数别省**
> - `encoding="utf-8-sig"`：兼容带 BOM 的 Excel 导出文件。
> - `newline=""`：避免 Windows 下每行之间多出空行。

### 按字典读取（更推荐）

```python
with open("scores.csv", encoding="utf-8-sig", newline="") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["姓名"], row["数学"])
```

每行变成一个字典，用列名取值，列顺序变了也不怕。

### 写入 CSV

```python
import csv

rows = [
    ["姓名", "语文", "数学", "英语"],
    ["小明", 90, 95, 88],
    ["小红", 85, 92, 96],
]

with open("out.csv", "w", encoding="utf-8-sig", newline="") as f:
    writer = csv.writer(f)
    writer.writerows(rows)
```

按字典写：

```python
with open("out.csv", "w", encoding="utf-8-sig", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["姓名", "数学"])
    writer.writeheader()
    writer.writerow({"姓名": "小明", "数学": 95})
```

> [!TIP]
> **用 Excel 打开不乱码**
> 写 CSV 时用 `encoding="utf-8-sig"`，Excel 能正确识别中文。

### 小案例：计算每人总分

```python
import csv

with open("scores.csv", encoding="utf-8-sig", newline="") as f:
    reader = csv.DictReader(f)
    for row in reader:
        total = int(row["语文"]) + int(row["数学"]) + int(row["英语"])
        print(row["姓名"], total)
```

CSV 读出来的值都是**字符串**，要计算先转换。

## 7.2 Excel 文件读写

```bash
pip install openpyxl
```

> `openpyxl` 只支持 `.xlsx` / `.xlsm`；老的 `.xls` 需要 `xlrd`（读）或 `xlwt`（写）。

### 读取工作簿

```python
from openpyxl import load_workbook

wb = load_workbook("data.xlsx", data_only=True)
print(wb.sheetnames)          # 所有工作表名

ws = wb.active                # 当前活动工作表
# ws = wb["Sheet1"]           # 按名字取

print(ws.max_row, ws.max_column)
print(ws["A1"].value)
print(ws.cell(row=2, column=3).value)
```

`data_only=True` 表示读公式的**计算结果**；否则读到的是公式文本。

### 遍历行

```python
for row in ws.iter_rows(min_row=2, values_only=True):
    name, chinese, math, english = row
    print(name, chinese + math + english)
```

`values_only=True` 直接拿值，不拿 Cell 对象，写起来更简洁。

### 写入 Excel

```python
from openpyxl import Workbook

wb = Workbook()
ws = wb.active
ws.title = "成绩表"

ws.append(["姓名", "数学", "英语"])
ws.append(["小明", 95, 88])
ws.append(["小红", 92, 96])

ws["A1"] = "姓名"              # 按单元格写
ws.cell(row=2, column=2, value=95)

wb.save("out.xlsx")
```

### 常用操作

```python
ws.insert_rows(2)             # 插入行
ws.delete_rows(3)             # 删除行
ws.column_dimensions["A"].width = 15   # 列宽
ws.freeze_panes = "A2"        # 冻结首行
```

> [!NOTE]
> **保存才会生效**
> openpyxl 的所有修改都在内存里，必须 `wb.save(路径)` 才写入磁盘；保存后原来打开的文件可能被占用，先关闭 Excel。

### 小案例：把 CSV 转成 Excel

```python
import csv
from openpyxl import Workbook

wb = Workbook()
ws = wb.active

with open("scores.csv", encoding="utf-8-sig", newline="") as f:
    for row in csv.reader(f):
        ws.append(row)

wb.save("scores.xlsx")
```

## 7.3 中文分词与关键字提取

### 为什么要分词

英文用空格天然分词，中文没有空格。`"我爱自然语言处理"` 需要切成 `["我", "爱", "自然语言", "处理"]`。

### jieba 三种模式

```bash
pip install jieba
```

```python
import jieba

text = "我来到北京清华大学"

print(jieba.lcut(text))                    # 精确模式（最常用）
print(jieba.lcut(text, cut_all=True))      # 全模式：所有可能的词
print(jieba.lcut_for_search(text))         # 搜索引擎模式：长词再切
```

| 模式 | 特点 | 用途 |
| --- | --- | --- |
| 精确模式 `cut` | 尽量不重复、不遗漏 | 文本分析、统计 |
| 全模式 `cut_all` | 列出所有可能词，有冗余 | 关键词召回 |
| 搜索模式 `cut_for_search` | 长词再切细 | 搜索引擎索引 |

### 添加自定义词

```python
jieba.add_word("大语言模型")
jieba.load_userdict("userdict.txt")   # 一行一个词，可带词频
```

人名、产品名、专业术语不在词典里时，会被切碎，需要手动加。

### 去停用词

停用词 = 「的、了、是、在、和」这类没有信息量的词。

```python
stopwords = set()
with open("stopwords.txt", encoding="utf-8") as f:
    for line in f:
        stopwords.add(line.strip())

words = [w for w in jieba.lcut(text)
         if w.strip() and w not in stopwords and len(w) > 1]
```

### 词频统计

```python
from collections import Counter

count = Counter(words)
for word, n in count.most_common(20):
    print(word, n)
```

### 案例：《三国演义》关键字提取

```python
import jieba
from collections import Counter

with open("三国演义.txt", encoding="utf-8") as f:
    text = f.read()

words = jieba.lcut(text)

stopwords = {"的", "了", "是", "在", "和", "我", "你", "他",
             "我们", "你们", "他们", "这", "那", "一个", "说道"}

filtered = [w for w in words
            if len(w) >= 2 and w not in stopwords and not w.isdigit()]

count = Counter(filtered)
for word, n in count.most_common(30):
    print(f"{word}: {n}")
```

流程可以套用到任何中文文本：

```text
读取 → 分词 → 过滤（长度/停用词/标点）→ 计数 → 排序 → 输出
```

### 关键词 vs 词频

词频高不代表「关键词」。更专业的做法：

- **TF-IDF**：一个词在本篇频率高、在其他篇频率低，才重要。`jieba.analyse.extract_tags(text, topK=20)`。
- **TextRank**：`jieba.analyse.textrank(text, topK=20)`。

```python
import jieba.analyse

keywords = jieba.analyse.extract_tags(text, topK=10, withWeight=True)
for word, weight in keywords:
    print(word, weight)
```

## 7.4 文本应用程序设计

### 7.4.1 图文打印与对齐

```python
print("姓名".center(10), "成绩".center(10))
print("-" * 25)
print("小明".center(10), "90".center(10))
```

注意：`center()` 按**字符数**补空格，一个汉字占两个显示宽度，中英混排时可能对不齐。可以借助 `unicodedata` 计算实际宽度：

```python
import unicodedata

def display_width(s):
    return sum(2 if unicodedata.east_asian_width(ch) in "WF" else 1
               for ch in s)

def pad(s, width):
    return s + " " * (width - display_width(s))
```

### 7.4.2 汉字排序

默认 `sorted()` 按 Unicode 编码排，不是拼音顺序。

```python
names = ["张三", "李四", "王五", "赵六"]
print(sorted(names))          # 按编码，不是拼音
```

按拼音排序：

```bash
pip install pypinyin
```

```python
from pypinyin import lazy_pinyin

print(sorted(names, key=lazy_pinyin))
```

按笔画/部首排序需要额外字典，教材案例通常用拼音即可。

### 7.4.3 案例：诗词平仄标注

古汉语声调分「平、上、去、入」，现代普通话大致对应：

- 一声、二声 → **平**
- 三声、四声 → **仄**

```python
from pypinyin import pinyin, Style

text = "床前明月光"
for char in text:
    info = pinyin(char, style=Style.TONE3, errors="ignore")
    tone = info[0][0][-1] if info and info[0][0][-1].isdigit() else ""
    level = "平" if tone in "12" else ("仄" if tone in "34" else "?")
    print(char, tone, level)
```

输出：

```text
床 2 平
前 2 平
明 2 平
月 4 仄
光 1 平
```

> [!NOTE]
> **简化规则**
> 这是现代普通话的近似标注，古音里的入声字（如「月」「白」「竹」）在现代可能已变成平声，严格标注需要古音字典。

### 7.4.4 案例：文本情感分析

```bash
pip install snownlp
```

```python
from snownlp import SnowNLP

text = "这部电影太好看了，强烈推荐！"
s = SnowNLP(text)
print(s.sentiments)      # 0~1，越接近 1 越正面
```

批量判断：

```python
texts = ["很好", "太差了", "一般般"]
for t in texts:
    score = SnowNLP(t).sentiments
    label = "正面" if score > 0.6 else ("负面" if score < 0.4 else "中性")
    print(t, round(score, 2), label)
```

> [!WARNING]
> **情感分析不是万能的**
> 反讽、双重否定、领域词（「这手机真薄」）容易误判。SnowNLP 基于电商评论训练，换领域效果会下降。

## ⚠️ 本章易错点

1. CSV 读取忘记 `newline=""`，Windows 下多空行。
2. 中文 CSV 用 `utf-8` 写出，Excel 打开乱码；应使用 `utf-8-sig`。
3. CSV 读出的数字是字符串，直接相加会拼接。
4. Excel 文件被占用时 `save()` 报 `PermissionError`。
5. `load_workbook` 不加 `data_only=True`，公式单元格读到的是 `=SUM(...)`。
6. jieba 没装或首次加载词典较慢，属正常现象。
7. 分词结果含标点、空白，统计前要过滤。
8. 停用词表编码不对，过滤不生效。
9. 把「词频最高」直接当「关键词」。
10. `pypinyin`、`SnowNLP` 是第三方库，需单独安装。

## 🧪 小练习

```python
# 统计一段中文里出现最多的 10 个两字词
import jieba
from collections import Counter

text = """自然语言处理是人工智能的重要方向。
自然语言处理让计算机理解人类语言。"""

print(Counter(words).most_common(10))
```
